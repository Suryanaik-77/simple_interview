🧠 Knowledge Assessment

1. If a fix improves setup slack in the SS corner but worsens hold in the FF corner, how does DMSA help?

  • DMSA cannot detect cross-corner impacts.
  • DMSA evaluates the fix on all workers simultaneously, so you see the hold degradation instantly before committing the change.
  • DMSA automatically reverts the fix if any corner degrades.
  • You need to re-run individual PT sessions to check.
Correct! Every ECO fix is evaluated across all corners at once. You see the impact on setup and hold simultaneously before deciding whether to keep or discard the change.

2. Can you add more scenarios to a running DMSA session?

  • No, all scenarios must be defined before start_hosts.
  • Yes, you can create additional scenarios and start new workers while the session is running, which is useful when new corners need to be checked.
  • Only if you restart all existing workers first.
  • Only if the new scenario uses the same libraries as an existing one.
Correct! DMSA supports dynamic scenario management. You can add corners on the fly as signoff requirements evolve.

3. What happens if one worker crashes during a DMSA session?

  • The entire DMSA session terminates.
  • All reports become invalid.
  • The master continues with the remaining workers. You can restart the failed scenario from its saved session without affecting other corners.
  • DMSA does not support worker recovery.
Correct! DMSA is resilient to individual worker failures. The master tracks which scenarios are active and you can re-launch a failed worker from its saved session.

4. In a production tapeout with 20+ corners, why is DMSA essential?

  • It reduces the number of corners needed to 4.
  • It eliminates the need for parasitic extraction.
  • Manually comparing 20+ individual reports is impractical and error-prone. DMSA gives you the true worst-case across all corners in one query and validates ECO fixes against all of them at once.
  • PrimeTime cannot run more than 4 individual sessions.
Correct! At production scale, DMSA is the only practical way to achieve timing signoff. It eliminates manual cross-corner tracking and ensures no corner is missed.
