🛠️ Tool: Calibre (Siemens EDA)
⏱️ Estimated Time: 60 minutes

🎯 Learning Objectives

  • Understand what Design Rule Check (DRC) verifies and why it is required before tapeout
  • Construct a Calibre DRC runset for the fill-merged GDS
  • Interpret DRC summary reports and results databases
  • Identify and fix common DRC runset errors

📚 Background: Design Rule Check

DRC verifies that the physical layout conforms to the foundry's manufacturing rules. Rules govern minimum widths, spacings, enclosures, overlaps, and densities for every layer. A clean DRC (zero violations) is required before a design can be submitted for fabrication.

DRC must be run on the fill-merged GDS (aes_cipher_top.fill.gds) because the fill shapes themselves may introduce new violations (e.g., fill-to-signal spacing) that must be checked.

Calibre DRC runset key statements:

  • LAYOUT PATH — must point to the fill-merged GDS, not the original
  • DRC RESULTS DATABASE — ASCII results file listing all violations
  • DRC SUMMARY REPORT — human-readable count per rule
  • INCLUDE — the TSMC 28nm DRC rule deck (calibre.drc)

🧠 Knowledge Check

1. Why must DRC be run on the fill-merged GDS rather than the original?

  • The original GDS does not contain metal layers
  • Fill shapes can introduce new spacing/density violations not present in the original layout
  • calibre.drc cannot read compressed GDS
  • DRC on the original would take too long
Correct! Fill shapes are subject to the same DRC rules as signal shapes, so the merged GDS must be checked.

2. What does "TOTAL RESULTS 0" in the DRC summary report indicate?

  • DRC did not run any checks
  • The run was aborted before checking
  • Zero DRC violations found — the layout is DRC clean
  • Maximum results limit was reached
Correct! Zero total results means the layout passes all design rules checked.

3. What is the purpose of DRC MAXIMUM RESULTS?

  • Limits how many violations are written to the results database to prevent enormous output files
  • Sets the maximum number of DRC rules to apply
  • Limits CPU usage during the DRC run
  • Controls the maximum allowed violation count before aborting
Correct! Setting a limit prevents the results file from becoming unmanageably large on a design with many violations.

4. Which TSMC 28nm PDK file is used as the DRC rule deck?

  • Dummy_Metal_Via_Calibre_28nm.13a
  • CLN28HP_9M.ANT_002.14a
  • calibre.drc
  • calibre.lvs
Correct! calibre.drc is the main DRC rule deck for TSMC 28nm.
