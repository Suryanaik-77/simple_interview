📚 Background: CDL Generation and LVS

Layout vs. Schematic (LVS) verifies that the physical layout (GDS) matches the circuit netlist (schematic). It extracts a netlist from the layout and compares it to the reference netlist. Any mismatch — missing connections, extra devices, swapped pins — is reported as an LVS violation.

For digital ASIC designs, the reference netlist is the post-route power-ground annotated Verilog (.pg.vg). Calibre LVS expects a SPICE/CDL format schematic, so a conversion step is needed first.

Step 1 — CDL generation using v2lvs:

v2lvs -v aes_cipher_top.pg.vg \
      -s tcbn28hpcplusbwp40p140_110a.spi \
      -o aes_cipher_top.cdl \
      -i aes_cipher_top

Step 2 — LVS run using Calibre:

calibre -turbo 2 -hier -lvs lvs_runset.rule

The LVS runset points SOURCE PATH to the generated CDL and LAYOUT PATH to the fill-merged GDS. A successful LVS ends with PASS in the report file.

🧠 Knowledge Check

1. What does LVS verify?

  • That the design meets timing constraints
  • That the physical layout matches the circuit netlist
  • That all metal layers have sufficient density
  • That DRC violations are zero
Correct! LVS compares extracted layout netlist against the reference schematic/CDL.

2. Why is v2lvs needed before running Calibre LVS?

  • Calibre cannot read GDS directly
  • Calibre LVS expects a SPICE/CDL schematic; the post-route netlist is in Verilog format
  • v2lvs compresses the netlist for faster LVS
  • v2lvs adds power/ground pins missing from the Verilog
Correct! v2lvs converts Verilog → CDL (SPICE) so Calibre can parse the schematic side of LVS.

3. In the LVS runset, SOURCE PATH points to:

  • The original post-route Verilog (.pg.vg)
  • The generated CDL file (aes_cipher_top.cdl)
  • The fill-merged GDS
  • The PDK SPICE library
Correct! SOURCE PATH is the schematic (CDL) side; LAYOUT PATH is the GDS side.

4. A successful Calibre LVS run ends with what text in the report?

  • LVS COMPLETE
  • PASS
  • TOTAL RESULTS 0
  • MATCH
Correct! Calibre LVS prints "PASS" in the LVS report when layout and schematic match.
