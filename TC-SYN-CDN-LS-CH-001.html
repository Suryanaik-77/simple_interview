📖 Design Information

iguana_soc is an open-source RISC-V SoC based on a CVA6 application processor. Unlike the tile design from Testcase 1, iguana_soc:

  • Is written in SystemVerilog (not plain Verilog)
  • Has multiple asynchronous clock domains
  • Contains three PSRAM macro instances with their own timing models
  • Requires uniquify after syn_generic due to shared module instances

Input files provided:

  • RTL filelist at /efs/semicon_labs_pd/designs/iguana_soc/iguana_soc_rtl.fl — source this directly; it sets $ver_files to the RTL source paths
  • inputs/iguana_soc_genus.sdc — timing constraints covering all clock domains

💡 Hints

Hint 1: Reading the RTL for iguana_soc

The RTL filelist lives on EFS, not in inputs/. Source it directly to set the variable $ver_files, then pass that variable to read_hdl: 

source /efs/semicon_labs_pd/designs/iguana_soc/iguana_soc_rtl.fl
read_hdl -language sv $ver_files

iguana_soc uses SystemVerilog constructs (interfaces, packages, logic, always_ff). The -language sv flag enables the SystemVerilog parser — this was not needed in Testcase 1 which used plain Verilog.

Hint 2: When to source the SDC and uniquify

For iguana_soc, the SDC is sourced after elaborate but before syn_generic — the same order as Testcase 1. Before sourcing the SDC, set the scan-sequence attribute: 

set_db use_scan_seqs_for_non_dft false

Also set the HDL search path before reading the RTL: 

set_db init_hdl_search_path {/efs/semicon_labs_pd/designs/iguana_soc/}

After sourcing the SDC, applying set_dont_use, and setting set_db timing_report_time_unit ns, run check_timing_intent and redirect output to ../reports/check_timing_intent_before_compile.rpt before syn_generic. See the Expected Reports section below for the reference output.

After syn_generic, run uniquify iguana_soc before syn_map. This creates a unique copy of every module that is instantiated more than once, so each instance can be optimized independently based on its local timing context.

After syn_map, define path groups before calling syn_opt. iguana_soc has six asynchronous clock inputs that must be excluded from in2out and in2reg groups: 

group_path -name reg2reg -from [all_registers -clock_pins] -to [all_registers -data_pins]
group_path -name in2out  -from [get_ports [remove_from_collection [all_inputs] {clk_i jtag_tck_i rtc_i slink_rcv_clk_i[0] usb_clk_i hyper_rwds_i[0]}]] -to [all_outputs]
group_path -name in2reg  -from [get_ports [remove_from_collection [all_inputs] {clk_i jtag_tck_i rtc_i slink_rcv_clk_i[0] usb_clk_i hyper_rwds_i[0]}]] -to [all_registers -data_pins]
group_path -name reg2out -from [all_registers -clock_pins] -to [all_outputs]
group_path -name mem2reg -from [get_pins -filter "is_clock_pin == true"  -of_objects [get_cells -hierarchical -filter "is_hard_macro == true"]] -to [all_registers -data_pins]
group_path -name reg2mem -from [all_registers -clock_pins] -to [get_pins -filter "is_clock_pin == false" -of_objects [get_cells -hierarchical -filter "is_hard_macro == true"]]
Hint 3: Cell restrictions and dont_use patterns

Apply the same set_dont_use strategy as Testcase 1 to block LVT cells and clock-tree cells. Additionally, the iguana_soc script uses a more targeted approach for one specific LVT cell that should remain allowed: 

set_dont_use [get_lib_cells {*LVT* */CK* */DEL* *D0* *D18* *D20* *D21* *D24* *D32*}]
set_db [get_db lib_cells -if {.base_cell.base_name == CKLNQD8BWP40P140LVT}] .dont_use false

The second line selectively re-enables the CKLNQD8BWP40P140LVT clock gating cell, which is needed for ICG insertion even though all other LVT cells are blocked.

Sequential data pins driven by a clock signal (3): The SDC creates two generated clocks — clk_gen_slo_drv and clk_gen_slo — on the Q outputs of flip-flops (clk_slow_reg and ddr_rcv_clk_o_reg). Since those Q outputs feed back into the D pins of downstream registers through combinational logic, Genus detects that data pins are driven by clock-derived signals. This is expected for the HyperBus receive-data-strobe domain and does not affect timing closure.

Loop-breaking cells for combinational feedback (48): 48 combinational feedback loops exist inside the CVA6 FPU block (i_multifmt_slice). 🧠 Knowledge Assessment

1. The iguana_soc script sets set_db use_scan_seqs_for_non_dft false after elaborate. What does this do?

  • It disables all scan chain insertion so the netlist has no DFT logic.
  • It tells Genus to treat all flip-flops as scan cells and connect them into a default scan chain.
  • It prevents Genus from using scan-sequence connectivity assumptions for non-DFT paths, ensuring that optimization and timing analysis use the functional connectivity only.
  • It removes all sequential elements from the design before synthesis begins.
Correct! When scan insertion has not yet been run, setting use_scan_seqs_for_non_dft false tells Genus not to assume scan-chain connectivity. This ensures optimization and timing analysis reflect the real functional netlist rather than scan-mode paths.

2. Why is uniquify iguana_soc needed after syn_generic?

  • It assigns unique names to all output files to avoid overwriting them.
  • It creates separate copies of modules instantiated more than once, so each instance can be optimized independently during cell mapping.
  • It removes duplicate standard cells inserted during generic synthesis.
  • It is required before sourcing the SDC to prevent clock name conflicts.
Correct! When multiple instances share the same module, the tool applies identical optimization to all of them. uniquify splits shared modules so each instance can be mapped and optimized independently based on its local timing context.

3. iguana_soc uses set_clock_groups -asynchronous in its SDC. What does this tell Genus?

  • It disables timing analysis for all clocks in the design.
  • It sets the clock uncertainty to zero for asynchronous paths.
  • It tells Genus not to analyze timing paths that cross between the listed clock groups, since those paths are handled by CDC synchronizers in RTL.
  • It marks all clocks as generated clocks derived from a single master clock.
Correct! Paths crossing asynchronous clock boundaries are handled by dedicated CDC synchronizers in RTL. Without set_clock_groups -asynchronous, Genus would try to meet impossible timing on those paths and generate misleading violations.

4. The read_hdl command for iguana_soc requires a flag not needed in Testcase 1. What is it and why?

  • -verilog, because iguana_soc uses older Verilog-95 syntax.
  • -sv, because iguana_soc is written in SystemVerilog which has constructs (interfaces, packages, logic, always_ff) that the standard Verilog parser does not support.
  • -hier, because iguana_soc has a deep module hierarchy requiring hierarchical elaboration.
  • -encrypt, because iguana_soc RTL is delivered in encrypted form.
Correct! iguana_soc is written in SystemVerilog. Passing -sv to read_hdl enables the SystemVerilog parser so constructs like interface, package, logic, and always_ff are recognized correctly.
