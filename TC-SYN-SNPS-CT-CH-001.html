🧠 Knowledge Check

Question 1: Which check_timing warning appears when input ports are not constrained relative to a clock?

  • Sequential clock pins with multiple clock waveforms
  • Inputs without clocked external delays
  • Outputs without external load
  • Generated clocks missing

Correct! The warning Inputs without clocked external delays appears when input ports do not have timing relationships defined relative to a clock.

Question 2: Which SDC command correctly removes the warning "Inputs without clocked external delays"?

  • set_input_delay -clock clk <delay> [get_ports data_in]
  • set_output_delay -clock clk <delay> [get_ports data_in]
  • create_clock -name clk -period <period> [get_ports data_in]
  • set_clock_uncertainty -setup <uncertainty> [get_clocks clk]

Correct! set_input_delay defines the arrival time of external signals relative to a clock.

Question 3: Which check_timing warning appears when output ports are not constrained relative to a clock?

  • Generated clocks missing
  • Outputs without clocked external delays
  • Sequential data pins driven by a clock signal
  • Timing exceptions with no effect

Correct! This warning occurs when output ports do not have timing constraints relative to a clock.

Question 4: Which SDC command correctly removes the warning "Outputs without clocked external delays"?

  • set_input_delay -clock clk <delay> [get_ports data_out]
  • set_output_delay -clock clk <delay> [get_ports data_out]
  • create_clock -name clk -period <period> [get_ports data_out]
  • set_load <capacitance> [get_ports data_out]

Correct! set_output_delay defines the required timing for outputs relative to a clock.

Question 5: Which check_timing warning appears when generated clocks are not defined in the SDC file?

  • Sequential clock pins without clock waveform
  • Inputs without clocked external delays
  • Outputs without external load
  • Nets with multiple drivers

Correct! This warning appears when derived clocks exist in the design but are not defined using create_generated_clock.

Question 6: Which SDC command defines a generated clock derived from another clock?

  • create_generated_clock -name gen_clk -source [get_ports clk] -divide_by 2 [get_pins divider/Q]
  • create_clock -name gen_clk -period <period> [get_ports gen_clk]
  • set_clock_uncertainty -setup <uncertainty> [get_clocks gen_clk]
  • set_input_delay -clock gen_clk <delay> [get_ports data]

Correct! create_generated_clock defines clocks derived from another clock source.
