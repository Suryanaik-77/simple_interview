🎯 Learning Objectives

📖 Theory and Background

The Routing Flow

Signal net routing is the final major physical operation before chip finishing. All standard cells are placed, the clock tree is built — now Innovus must connect every signal net by assigning metal wires and vias across the 9-layer metal stack, while satisfying DRC rules, meeting timing, and avoiding antenna violations.

Routing Phase What it does Innovus Command
Global Routing Assigns nets to coarse routing regions (G-cells) — establishes the routing topology without full DRC compliance route_global
Detail Routing Completes exact wire and via assignments within each region — meets all DRC spacing, width, and via rules route_detail
Antenna Repair Fixes antenna violations by inserting diodes or re-routing long stubs that accumulated charge during etch route_fix_antenna
DRC Verification Confirms the fully routed design is DRC-clean verify_drc

📈 Metal Layer Routing Constraints at TSMC 28nm

Layer Direction Routing Use
M1 Horizontal (restricted) Local connections only — cell internal wiring, standard cell pin access. Cannot be used for global signal routing.
M2 Vertical Minimum layer for global signal routing. Short-distance connections between nearby cells.
M3–M5 Alternating H/V Intermediate signal routing — local fanout distribution within standard cell blocks.
M6–M7 Alternating H/V Longer signal routing — block-to-block connections, used for clock trunk NDR routing.
M8–M9 H/V Power stripes primarily — signal routing only for very long global connections.
⚠ Critical rule: Setting route_design_signal_min_layer M1 is incorrect. M1 is used exclusively by standard cells for internal pin connections. If the signal router tries to use M1 for net connections, it creates DRC violations with cell internal routing and can cause shorts or opens. Always set the minimum to M2.

⚡ Antenna Effect and route_fix_antenna

During chip manufacturing, long metal wire stubs act as antennas that accumulate plasma charges during the etch process. If the accumulated charge exceeds the gate oxide breakdown threshold of the transistors connected to that wire, the transistors are permanently damaged. The antenna ratio is the ratio of the wire area to the gate area — a ratio above the PDK limit triggers an antenna violation.

route_fix_antenna resolves antenna violations by: (1) inserting a protection diode at the antenna endpoint to drain accumulated charge, or (2) re-routing the wire to add a via that "jumps" to a higher metal layer, breaking the antenna length.

📝 Knowledge Assessment Quiz

Test your understanding of signal net routing concepts.

1. Why is M1 restricted to local connections only and cannot be used as the minimum signal routing layer?

  • Because M1 is too thin to carry signal current without electromigration failures
  • Because the Innovus router does not have routing grid definitions for M1
  • M1 is used by standard cells for internal pin access wiring — if the signal router places global connections on M1, they will conflict with cell-internal M1 geometry, creating DRC spacing and width violations that cannot be resolved
  • M1 routing requires a special license in Innovus that is not available in this lab environment
Correct! Standard cells reserve M1 for their internal connections — the cell pins are accessed on M1. The routing grid for M1 within a cell is managed by the cell library, not by the signal router. If the global router also places connections on M1, it creates conflicts with cell-internal wiring that violate minimum spacing and enclosure rules. M2 is the first layer available to the signal router for general-purpose routing.

2. What is the purpose of assigning a Non-Default Rule (NDR) to clock propagated nets before route_detail?

  • To prevent the router from using clock nets for signal routing, reserving them for power
  • To assign clock nets to dedicated routing tracks on M8–M9 away from signal congestion
  • Clock nets require wider metal and increased spacing compared to signal nets — wider metal reduces resistivity (improving transition time) and extra spacing reduces capacitive coupling from adjacent signal nets that could inject glitches onto the clock
  • NDR rules mark clock nets as don't-touch so route_detail does not move them from their CTS-assigned positions
Correct! Clock nets are the most sensitive nets in the design — any glitch or noise coupling onto the clock causes metastability or setup/hold violations at every flip-flop the clock drives. NDR rules provide shielding by increasing the spacing between the clock wire and adjacent signal wires, reducing capacitive crosstalk. The wider metal reduces RC delay along the clock wire, maintaining sharp transitions.

3. After route_detail, verify_drc reports 150 DRC violations. Before running route_fix_antenna, you want to separate antenna violations from other DRC errors. How can you distinguish them?

  • Antenna violations always appear on M1 — any DRC on M1 is an antenna error
  • Antenna violations have slack values < 0 in the timing report
  • Run report_route_drc which categorizes violations by type — antenna violations appear as a separate category (typically labeled ANTENNA or ANT). Non-antenna DRC errors (spacing, width, enclosure) appear under different rule categories
  • Antenna violations can only appear after route_fix_antenna runs, so all 150 violations are non-antenna DRC errors at this stage
Correct! report_route_drc provides a categorized summary of all DRC violations with rule names and counts. Antenna violations are reported as a distinct rule category (e.g., "ANTENNA" or "ANT_RATIO"). By checking this report before running route_fix_antenna, you can see exactly how many violations are antenna-related vs. spacing/width/enclosure issues, helping prioritize debugging.

4. route_design_concurrent_minimize_via_count_effort high is set before routing. What effect does minimizing via count have on timing?

  • Fewer vias reduces the routing area, allowing more signal nets to fit on lower metal layers
  • Via minimization has no effect on timing — only wire length determines signal delay
  • Each via adds resistance and capacitance to a net's RC profile — fewer vias reduces net delay, improving timing slack especially for critical paths with multiple layer changes
  • Via minimization reduces electromigration risk on power nets by spreading current across fewer contacts
Correct! A via contributes both resistance (typically 5–50 ohms per via depending on layer and process) and capacitance to the net. For a critical path with 10 layer changes, reducing each via stack from 2 contacts to 1 contact can save several tens of picoseconds of delay — significant when the slack budget is tight. Via minimization with "high" effort invests more CPU time but produces better timing results on critical nets.
