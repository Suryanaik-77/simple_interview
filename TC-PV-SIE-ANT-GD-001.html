🧠 Knowledge Assessment

1. What is an antenna violation in the context of chip design?

  • A signal integrity issue caused by long wire routing
  • Charge accumulation on a floating gate during metal etching that can damage the gate oxide
  • Excessive capacitance on clock nets causing timing violations
  • A DRC spacing violation on metal layers
Correct! During plasma etching, charge builds up on exposed metal connected to a gate. If the metal-to-gate area ratio exceeds the PDK limit, the gate oxide can be permanently damaged.

2. In the antenna runset, what does DRC MAXIMUM RESULTS 50 control?

  • The maximum number of antenna rules to check
  • The maximum run time allowed for the antenna check
  • The maximum number of violations written to the results database per rule
  • The maximum number of CPU threads used
Correct! It caps output per rule to avoid very large results files on designs with widespread violations.

3. What is the role of the INCLUDE statement in the antenna runset?

  • It includes additional GDS layers to check
  • It references a library of standard cell models
  • It loads the PDK antenna rule deck that defines the antenna ratio limits and check logic
  • It sets the technology process corner for the check
Correct! The antenna rule deck (CLN28HP_9M.ANT_002.14a) contains all the foundry-specified antenna ratio rules. Without it Calibre has no rules to apply.

4. Where is the antenna check summary report written after a successful run?

  • In the WORK/ directory as a temporary file
  • Printed to the terminal only
  • To outputs/aes_cipher_top.antenna.summary as specified by DRC SUMMARY REPORT in the runset
  • In the PDK rule deck directory
Correct! The DRC SUMMARY REPORT path in the runset controls where the human-readable summary (with TOTAL RESULTS count) is written.
