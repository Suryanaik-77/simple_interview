📖 Theory and Background

What is Synthesis?

In VLSI, synthesis is the process of translating your Register-Transfer Level (RTL) design, written in languages like Verilog or VHDL, into a gate-level netlist. The synthesis tool optimizes for Power, Performance, and Area (PPA) during this conversion.

Understanding the Linking Phase

After reading your RTL files, Design Compiler performs a "linking" operation. This process happens during the elaboration stage, where the tool prepares your design for synthesis.

During this phase, the tool performs three essential checks:

  • Resolves module references: Connects instantiated modules to their definitions
  • Checks hierarchy: Ensures all submodules are available
  • Validates library cells: Confirms standard cells exist in the technology library

Common Unresolved Reference Errors

UID-341 Warning: UID-341 (warning) Design '%s' has '%d' unresolved references. For more detailed information, use the "link" command.

This indicates Design Compiler cannot find the definition of a module that is instantiated in your design.

LINK-5 Warning: LINK-5 (warning) Unable to resolve reference '%s' in '%s'.

Similar to UID-341, this appears during the link command and indicates missing module definitions.

Root Causes:

  • Missing RTL file: The file containing the module definition wasn't added to the filelist
  • Typo in module name: Instantiation name doesn't match the defined module name
  • Missing library file: Standard cell not found in technology library (for std cells)
  • Incorrect search path: DC cannot locate the file even if it exists
  • Port mismatch: Module definition has different ports than instantiation

💡 Lab Focus: The Two Main Culprits

Throughout these testcases, you will be solving the two most frequent issues encountered in synthesis:

  • Missing Source Files: Adding missing RTL files to the filelist.
  • Library Configuration Issues: Resolving path errors or missing macro/standard cell databases in the link_library variable.

📝 Knowledge Assessment Quiz

Question 1: What does the LINK-5 warning indicate?

  • A. Syntax error in the RTL code
  • B. Design Compiler cannot find the definition of an instantiated module
  • C. Timing constraint violation
  • D. Library cell is missing

Correct! LINK-5 warnings appear during the linking phase when Design Compiler has read a module that instantiates another module, but it cannot find the definition of that instantiated module.

Question 2: Which command is used to connect module instantiations to their definitions in DC?

  • A. compile
  • B. synthesize
  • C. link
  • D. analyze

Correct! The link command in Design Compiler resolves all module references and connects instantiated modules to their definitions.

Question 3: Which variable is primarily used to resolve standard cell and macro library databases (.db files)?

  • A. search_path
  • B. link_library & target_library
  • C. synthetic_library
  • D. rtl_files

Correct! The link_library variable is used to reference required memory macros and standard cell databases, which helps avoid library-related errors.

Question 4: At which stage does Design Compiler validate that standard cells exist in the technology library?

  • A. Reading RTL
  • B. Linking Phase
  • C. Post-Synthesis Timing Analysis
  • D. Floorplanning

Correct! During the linking phase of the elaboration stage, the tool validates that all standard cells exist in the technology library.
