🧭 What this lab is

A multiplier verified with python3 in the loop: python computes the golden expected values the testbench compares against. It shows how python glue - the backbone of real regression tooling - integrates with an HDL simulation.

⚙️ How it runs

run.sh coordinates python3 and VCS; the python script (refmodel.py) does its part and the run ends with a machine-readable verdict. Guided passes; a DUT bug makes python (or the python-fed self-check) report a failure.

🎯 What you'll learn
  • Integrate a python3 script into a simulation flow
  • Use python for python computes the golden expected values the testbench compares against
  • Return a machine-readable verdict a flow can score
