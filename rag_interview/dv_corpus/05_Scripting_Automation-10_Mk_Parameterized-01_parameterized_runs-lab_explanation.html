🧭 What this lab is

A self-checking DUT whose run length is a Makefile/plusarg variable.

💡 The concept

A make variable forwarded into the run wrapper's plusargs changes a run without editing files.

⚙️ How it works

Run NUM_CYCLES=40 make and see the run length change via the forwarded variable.

🎯 What you'll learn
  • Forward a make variable into a plusarg
  • Override a parameter from the command line
  • Expose runtime knobs through the build
🔧 Key constructs
make variableplusarg forwarding
