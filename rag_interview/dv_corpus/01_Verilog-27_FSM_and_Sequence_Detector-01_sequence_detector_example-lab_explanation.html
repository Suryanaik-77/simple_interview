🧠 Knowledge Check

Q1: In a Mealy FSM, the output depends on:

  • Only the current state
  • Only the current input
  • Both the current state and the current input
  • The previous state only

A Mealy machine's output is a function of both state and input, making it potentially faster (output changes within the same clock cycle) but harder to pipeline.

Q2: A Moore FSM outputs '1' only in state S3. What is the minimum number of flip-flops needed for 5 states?

  • 2
  • 3
  • 4
  • 5

5 states require ceil(log2(5)) = 3 flip-flops to encode in binary. (One-hot encoding would require 5 flip-flops.)

Q3: You want to detect the sequence '1011' with overlapping matches (e.g., '10110111' gives 2 matches). What must the FSM do after a match?

  • Return to the initial state
  • Jump back to the state that represents the longest prefix of the pattern that is also a valid suffix
  • Halt
  • Ignore further input for one cycle

For overlapping detection, the FSM must transition to the state representing the longest overlap between the matched suffix and a pattern prefix — exactly the KMP failure-function concept.

Q4: In a one-hot encoded FSM with 8 states, one flip-flop gets stuck at 1. How many states appear active simultaneously?

  • 1
  • 2
  • 0 — the FSM locks up
  • Depends on transition logic

One-hot encoding requires exactly one flip-flop to be 1 at any time. If one is stuck, the currently active state AND the stuck state are both 1 — an illegal combination that most state decoders will misinterpret.

Q5: Which coding style is preferred for the state register in synthesisable Verilog?

  • always @(*) with blocking assignments
  • always @(posedge clk) with non-blocking assignments
  • assign statement with a ternary operator
  • initial block with blocking assignments

The state register is sequential (clocked) logic. Use always @(posedge clk) with <= non-blocking assignments to correctly model flip-flop behaviour.
