🧠 Knowledge Check

Q1: What is the 4-state value of an undriven <code>wire</code>?

  • 0
  • 1
  • x
  • z

An undriven net defaults to z (high-impedance) in Verilog. The value x appears when a net is multiply driven with conflicting values.

Q2: Which SV type is a 2-state equivalent of <code>reg</code>?

  • logic
  • bit
  • integer
  • byte

bit is a 2-state (0/1 only) single-bit variable. logic is 4-state like reg but resolves drive conflicts.

Q3: A <code>logic [3:0]</code> variable is left uninitialized in an always_comb block. What is its value?

  • 4'b0000
  • 4'bxxxx
  • 4'bzzzz
  • Undefined — compile error

Uninitialized 4-state variables hold x. This is a common source of simulation mismatches — always assign a default inside always_comb.

Q4: What happens when you assign -1 to a <code>logic [7:0]</code> variable?

  • Compile error
  • 8'b00000000
  • 8'b11111111
  • 8'bxxxxxxxx

Signed integer -1 in two's complement is all 1s. When assigned to an unsigned 8-bit vector it becomes 8'hFF.

Q5: Which declaration correctly defines a 32-bit signed variable in SystemVerilog?

  • reg signed [31:0] a
  • logic signed [31:0] a
  • int a
  • Both B and C

Both logic signed [31:0] and int (which is implicitly 32-bit signed) are correct. reg signed [31:0] is also valid Verilog but reg is deprecated in SV.
