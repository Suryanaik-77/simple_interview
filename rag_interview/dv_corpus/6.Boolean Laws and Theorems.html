Boolean Algebra Laws

Boolean Algebra is a mathematical system for manipulating variables that can have only two values: TRUE (1) or FALSE (0). It's the mathematical foundation of all digital circuit design.

1. Basic Boolean Laws

Identity Law

  • A + 0 = A
  • A • 1 = A

Null Law

  • A + 1 = 1
  • A • 0 = 0

Idempotent Law

  • A + A = A
  • A • A = A

Inverse Law

  • A + Ā = 1
  • A • Ā = 0

2. Distributive Law

Distributive Law

A • (B + C) = (A • B) + (A • C)

AND distributes over OR

Dual Distributive Law

A + (B • C) = (A + B) • (A + C)

OR distributes over AND

3. De Morgan's Theorems

Most Important Theorems in Digital Design! These allow conversion between AND/OR and NAND/NOR gates.

De Morgan's First Theorem

A + B = Ā • B̄

Rule: The complement of an OR operation equals the AND of the complements

De Morgan's Second Theorem

A • B = Ā + B̄

Rule: The complement of an AND operation equals the OR of the complements

Consensus Theorem (or) Redundancy Theorem

Rule:

a) Variable must present in complemented form.

b) Take Three variables must present in the expression.

c) Each variable is repeated twice.

d) One those terms which contain the complemented variable.

  • A•B + Ā•C + B•C = A•B + Ā•C

    • The consensus term B•C is redundant

  • (A+B).(A'+C).(B+C) = (A+B).(A'+C)

    • [Dual form]

Complete Simplification Example

Problem: Simplify the expression Y = A•B + A•B̄ + Ā•B

Step 1: Apply Distributive Law
Y = A•B + A•B̄ + Ā•B
Y = A•(B + B̄) + Ā•B

Step 2: Apply Inverse Law (B + B̄ = 1)
Y = A•1 + Ā•B
Y = A + Ā•B

Step 3: Apply Distributive Law in reverse
Y = (A + Ā) • (A + B)

Step 4: Apply Inverse Law (A + Ā = 1)
Y = 1 • (A + B)

Step 5: Apply Identity Law (1 • X = X)
Y = A + B

Final Result: Y = A + B

Achievement: We simplified a 3-term expression with 6 literals to a 2-term expression with 2 literals!

Circuit Reduction: Original needed 3 AND gates + 1 OR gate → Simplified needs just 1 OR gate!

❓Check Your Understanding

1. Simplify Z = X•Y + X'•Z + Y•Z

  • Z = X•(Y + Z) + Y•Z
  • Z = (X + Y)•(X + Z)•(Y + Z)
  • Z = X•Y + X'•Z
  • Z = X•Y + Y•Z

Correct Answer: Z = X•Y + X'•Z

Explanation: This is an application of the Consensus Theorem:

X•Y + X'•Z + Y•Z = X•Y + X'•Z

Circuit Impact: Removes one AND gate (Y•Z)!

2. Which Boolean law is demonstrated by: A + (A • B) = A

  • Distributive Law
  • De Morgan's Theorem
  • Absorption Law
  • Inverse Law

Correct Answer: Absorption Law

Absorption Law Examples:

  • A + (A • B) = A
  • A • (A + B) = A

Intuitive Explanation: The larger term "absorbs" the smaller term.

3. Simplify: F = (A + B) • (Ā + C) • (B + C)

  • F = A•B + Ā•C
  • F = (A + B) • (Ā + C)
  • F = B + C
  • F = A•C + B•C

Correct Answer: F = (A + B) • (Ā + C)

Step-by-step Solution:

  1. Original: F = (A + B) • (Ā + C) • (B + C)
  2. Apply consensus theorem: F = (A + B) • (Ā + C)

Gate Reduction: Removes one OR gate (B+C)!

4. What is the result of A • Ā using Boolean laws?

  • A
  • 1
  • 0
  • Ā

Correct Answer: 0

Explanation: This is the Inverse Law: A • Ā = 0

A variable AND its complement always equals 0.

5. Apply De Morgan's theorem to: Y = A • B • C

  • Y = Ā + B̄ + C̄
  • Y = Ā • B̄ • C̄
  • Y = A + B + C
  • Y = Ā + B̄ • C̄

Correct Answer: Y = Ā + B̄ + C̄

Step-by-step:

  1. Complement both sides: Ȳ = A • B • C
  2. Apply De Morgan: Ȳ = Ā + B̄ + C̄
  3. Complement again: Y = Ā + B̄ + C̄

6. Simplify using identity law: X + 0 = ?

  • X
  • 0
  • 1
  • X̄

Correct Answer: X

Explanation: This is the Identity Law: A + 0 = A

Anything OR 0 equals itself.

7. What does the consensus theorem state about A•B + Ā•C + B•C?

  • It equals A + B + C
  • It equals A•B + Ā•C
  • It equals Ā + B̄ + C̄
  • It cannot be simplified

Correct Answer: It equals A•B + Ā•C

Consensus Theorem: A•B + Ā•C + B•C = A•B + Ā•C

The term B•C is redundant and can be eliminated.

8. What is A + 1 according to Boolean algebra?

  • A
  • 1
  • 0
  • Ā

Correct Answer: 1

Explanation: This is the Null Law: A + 1 = 1

Anything OR 1 equals 1.

9. Which law states that A • A = A?

  • Inverse Law
  • Identity Law
  • Idempotent Law
  • Distributive Law

Correct Answer: Idempotent Law

Idempotent Law Examples:

  • A • A = A
  • A + A = A

Redundant inputs don't change the output.

10. Simplify: Y = A•B + A•B̄

  • A
  • B
  • A + B
  • 0

Correct Answer: A

Step-by-step:

  1. Y = A•B + A•B̄
  2. Factor out A: Y = A•(B + B̄)
  3. Apply inverse law: B + B̄ = 1
  4. Y = A•1 = A

📝 Key Takeaways

Boolean Algebra Foundation

All digital circuit optimization is based on Boolean algebra laws and theorems

Distributive Law

A•(B+C) = A•B + A•C and A+(B•C) = (A+B)•(A+C) - essential for factoring/expanding

De Morgan's Theorems

A+B = Ā•B̄ and A•B = Ā+B̄ - enables gate type conversion and NAND/NOR implementations

Absorption Law

A + A•B = A - removes redundant terms from expressions

Consensus Theorem

Identifies redundant terms: A•B + Ā•C + B•C = A•B + Ā•C

Cost Reduction

Boolean simplification directly reduces gate count, chip area, power, and cost
