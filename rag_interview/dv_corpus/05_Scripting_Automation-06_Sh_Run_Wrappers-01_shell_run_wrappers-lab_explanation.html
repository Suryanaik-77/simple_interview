🧭 What this lab is

A self-checking counter that is driven by a portable shell wrapper that selects the simulator and forwards plusargs. It shows the scripting tool of this group at work in a real simulation flow.

⚙️ How it runs

run.sh coordinates the tool and VCS; the testbench self-checks and prints the verdict token. Guided passes; a DUT bug makes the self-check report a failure.

🎯 What you'll learn
  • Drive a simulation with this group's scripting tool
  • Keep the flow reproducible and portable
  • Read the verdict a flow scores
🔧 Key constructs
shell wrapperrun.shSIM selectplusarg forward
