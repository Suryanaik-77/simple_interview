🧭 What this challenge is

The same SVA-checked handshake, but one planted bug in the design makes a bound assertion fire under VCS -assert. Read which property failed and fix the RTL.

🛠️ Debugging Guide
🔴 Symptom

VCS reports repeated FAIL: a_ack - the design drives gnt low forever, so every request goes ungranted.

🔎 How to investigate
  1. Read the FAIL lines - a_ack fires one cycle after each request.
  2. Open the design .sv and read the else branch of the clocked block.
  3. Note gnt is tied to 0 instead of following req.
🧭 Fix direction

Drive the grant from the request: change the else assignment to gnt <= req;

✅ Confirm

Re-run ./run.sh; a_ack no longer fires and the run ends with RESULT: TEST PASSED.
