🧭 What this lab is

A self-checking DUT whose run length is chosen at run time by the +NUM_CYCLES plusarg, demonstrating runtime control of a fixed build.

💡 The concept

The testbench reads +NUM_CYCLES with $value$plusargs and falls back to a default when it is absent; changing the value changes the run while the same simv is reused.

⚙️ How it works

Run ./run.sh vcs, then NUM_CYCLES=40 ./run.sh vcs, and see the run length change without a rebuild while the verdict stays correct.

🎯 What you'll learn
  • Read a runtime value with $value$plusargs and default it when absent
  • Reuse one compiled model across many parameterized runs
  • Explain why plusargs belong at run time, not compile time
