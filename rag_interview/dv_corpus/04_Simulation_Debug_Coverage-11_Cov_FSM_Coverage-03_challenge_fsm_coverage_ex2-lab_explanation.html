🧭 What this challenge is

The same design and stimulus, but one bug leaves a construct unexercised, so the urg coverage SCORE falls below the goal. Read the report, find the hole, and fix the RTL so it is reachable.

🛠️ Debugging Guide
🔴 Symptom

urg FSM coverage is below 100% - RUN holds forever, so DONE is never reached.

🔎 How to investigate
  1. Run make report and inspect FSM state coverage.
  2. Note RUN transitions to itself and never advances.
  3. DONE has zero coverage.
🧭 Fix direction

Advance RUN to DONE: RUN: state <= DONE;

✅ Confirm

Re-run ./run.sh; coverage returns to 100% and the run ends with RESULT: TEST PASSED.
