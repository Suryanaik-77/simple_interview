🧭 What this challenge is

The same seeded regression, but a bug in the adder makes runs fail. Read run.sh's aggregate output and regr.log, reproduce a failing seed, and fix the RTL so the regression is clean.

🛠️ Debugging Guide
🔴 Symptom

The regression reports failed seeds: whenever the random a+b exceeds 255 the masked sum loses the carry and mismatches the 9-bit reference.

🔎 How to investigate
  1. Read run.sh's per-seed output and open regr.log to see which seeds failed.
  2. Re-run a failing seed directly: ./simv +SEED=<n>, and read the FAIL line's a, b, sum values.
  3. Note sum is masked to 8 bits, dropping the 9th (carry) bit.
🧭 Fix direction

Keep the full 9-bit result: sum = {1'b0, a} + {1'b0, b};

✅ Confirm

Re-run ./run.sh; all seeds pass and the run ends with RESULT: TEST PASSED.
