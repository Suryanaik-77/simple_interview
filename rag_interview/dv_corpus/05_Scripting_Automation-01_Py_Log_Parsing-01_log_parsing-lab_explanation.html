🧭 What this lab is

A multiplier verified with python3 in the loop: python parses the simulation log and decides pass/fail. It shows how python glue - the backbone of real regression tooling - integrates with an HDL simulation.

⚙️ How it runs

run.sh coordinates python3 and VCS; the python script (parse_log.py) does its part and the run ends with a machine-readable verdict. Guided passes; a DUT bug makes python (or the python-fed self-check) report a failure.

🎯 What you'll learn
  • Integrate a python3 script into a simulation flow
  • Use python for python parses the simulation log and decides pass/fail
  • Return a machine-readable verdict a flow can score
