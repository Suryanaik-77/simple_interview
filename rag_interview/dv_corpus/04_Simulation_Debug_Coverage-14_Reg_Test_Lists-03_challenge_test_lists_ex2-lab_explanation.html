🧭 What this challenge is

The same seeded regression, but a bug in the adder makes runs fail. Read run.sh's aggregate output and regr.log, reproduce a failing seed, and fix the RTL so the regression is clean.

🛠️ Debugging Guide
🔴 Symptom

The regression fails on every seed: the sum is always one greater than the reference.

🔎 How to investigate
  1. Read the per-seed FAILs; each shows sum = expected + 1.
  2. Re-run one seed: ./simv +SEED=<n> and inspect the constant offset.
  3. Find the extra + 1 in the adder.
🧭 Fix direction

Remove the stray increment: sum = {1'b0, a} + {1'b0, b};

✅ Confirm

Re-run ./run.sh; all seeds pass and the run ends with RESULT: TEST PASSED.
