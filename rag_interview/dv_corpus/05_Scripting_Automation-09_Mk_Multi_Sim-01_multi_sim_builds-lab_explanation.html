🧭 What this lab is

A self-checking DUT whose Makefile parameterizes over simulators with a SIM variable.

💡 The concept

A SIM variable overridable on the command line lets one set of targets drive vcs, xrun, or iverilog.

⚙️ How it works

Run make SIM=vcs and note the same targets would accept SIM=xrun.

🎯 What you'll learn
  • Parameterize a build with a SIM variable
  • Override make variables on the command line
  • Keep targets tool-portable
🔧 Key constructs
SIM variablemake override
