🛠️ Debugging Guide
🔴 Symptom

The self-check reports FAIL on cycles where en is low - the counter advances when it should hold.

🔎 How to investigate
  1. Read the FAIL lines - mismatches occur on en=0 cycles.
  2. Open the design and read the else branch.
  3. The enable gate is missing.
🧭 Fix direction

Gate the increment with enable: else if (en) count <= count + 4'd1;

✅ Confirm

Re-run ./run.sh; the self-check passes and the run ends with RESULT: TEST PASSED.
