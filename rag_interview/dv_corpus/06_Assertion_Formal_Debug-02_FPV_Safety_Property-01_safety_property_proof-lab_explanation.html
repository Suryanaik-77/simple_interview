🧭 What this lab is

A saturating counter whose safety invariant - count never exceeds 12 - is proven to hold on every reachable state, demonstrating how a bad state is shown to be unreachable rather than merely never hit in simulation.

💡 The concept

A safety property asserts that something bad never happens: here, an invariant that count stays within its bound. Formal discharges it by proving no reachable state violates it (or returns a shortest counterexample trace if one exists).

🔧 The property under proof

The safety property asserts an invariant: on every reachable state the count never exceeds 12. Formal proves this with no reachable counterexample.

assert property (count <= 12);   // safety invariant - must hold on every reachable state
⚙️ The formal flow

run.sh calls JasperGold on prove.tcl: analyze design + property, elaborate, set clock and reset, prove -all. The invariant is proven unbounded.

jg -batch -tcl prove.tcl
  analyze -sv fpv_safety.sv fpv_safety_props.sv
  elaborate -top fpv_safety
  clock clk ; reset rst ; prove -all
🎯 What you'll learn
  • State a safety property as an invariant assertion
  • Understand what a counterexample trace tells you
  • See why formal proof is stronger than never hitting the state in simulation
