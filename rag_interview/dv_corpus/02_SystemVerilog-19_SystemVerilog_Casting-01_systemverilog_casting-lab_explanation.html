🧭 What this lab is

19_SystemVerilog_Casting.sv and its testbench tb_19_SystemVerilog_Casting.sv walk through the full range of SystemVerilog casts in one comprehensive demo: enum casting, packed-struct/bit-stream casting, signed vs. unsigned arithmetic casting, and class-hierarchy casting with $cast.

💡 The concept

The lab distinguishes two families of casts. Static casts (type'(expr)) are resolved at compile time — they reinterpret an expression's bits as another type with no runtime check, which is exactly the tool needed to widen an 8-bit multiply into 16 bits before the multiplication happens, or to convert raw bits into an enum literal. Dynamic casts ($cast(dest, src)) are runtime, checked operations used for class handles: assigning a base-class handle to a derived-class variable is unsafe unless the actual object is genuinely of that derived type, so $cast verifies the type and returns a 0/1 status instead of corrupting the handle or crashing.

⚙️ How it works

The DUT-side file defines two enums, state_e (a 3-bit encoded FSM enum) and command_e (a plain int enum), a packed struct packet_t (header/address/data/checksum) for bit-stream casting, and a class hierarchy Animal → Dog/Cat with a virtual speak() and get_type() for dynamic-cast demonstrations. The testbench tb_19_SystemVerilog_Casting instantiates five demo modules — static_cast_demo, enum_cast_demo, bitstream_cast_demo, class_cast_demo, and special_casts_demo — each of which runs its own casting scenarios in an initial block. After letting those run for #100, the top-level initial block calls test_expression_casting(), which shows the classic arithmetic-truncation bug: result = a * b on two logic [7:0] operands multiplies in 8-bit precision and truncates, whereas result = 16'(a) * 16'(b) static-casts each operand to 16 bits *before* multiplying, preserving full precision. The testbench then calls test_array_casting() and test_union_casting() before print_summary() and $finish.

🎯 What you'll learn
  • How static cast width'(expr) changes the evaluation width of an expression before an operation, not just the result
  • How to use $cast() for both enum-from-bits validation and class-hierarchy downcasting, and why its return value must be checked
  • How bit-stream casting reinterprets a packed struct's raw bits (e.g. packet_t) as a flat vector and vice versa
  • The difference between compile-time (static) and runtime (dynamic) casting, and when each is appropriate
⚠️ Common mistakes
  • Forgetting to cast operands before an arithmetic operation (e.g. a * b instead of 16'(a) * 16'(b)), so truncation happens inside the operation rather than after it
  • Using a plain assignment or static cast for class handles instead of $cast, so an invalid downcast silently produces a null/garbage handle instead of a checkable failure
