Logic Gates

  • Key Concept: Logic gates are electronic circuits that take one or more binary inputs (0 or 1) and produce a single binary output based on a specific logical operation.

  • AND: Any one of the input is low output is low
  • OR: Any one of the input is high output is high
  • NOT: Complemented input
  • NAND: Any one of the input is low output is high
  • NOR: Any one of the input is high output is low
  • XOR: Odd number of inputs are high output is high
  • XNOR: Even number of inputs are low output is high

1.Which logic gate would you use if you want the output to be HIGH only when EXACTLY ONE of two inputs is HIGH?

  • AND Gate
  • OR Gate
  • XOR Gate
  • XNOR Gate

Correct Answer: XOR Gate

Explanation: The XOR (Exclusive OR) gate produces a HIGH output only when the inputs are DIFFERENT. If exactly one input is HIGH (and the other is LOW), the output will be HIGH.

Memory Tip: XOR = "eXactly One is tRue"

  • 0, 0, 0, 1
  • 1, 0, 0, 0

3.Why are NAND and NOR gates called "universal gates"?

  • Because they're used universally in all countries
  • Because they have the simplest truth tables
  • Because you can create ANY other logic gate using only NAND gates or only NOR gates
  • Because they were the first gates invented

Correct Answer: Because you can create ANY other logic gate using only NAND gates or only NOR gates

Explanation: Universal gates can implement all basic Boolean functions. For example:

  • NOT gate using NAND: Connect both inputs together
  • AND gate using NAND: NAND followed by NOT (made from NAND)
  • OR gate using NAND: More complex combination possible

This property makes them incredibly valuable in digital circuit design.

4.A washing machine should start ONLY when:

  1. The door is closed
  2. Water is available
  3. Either the "Start" button is pressed OR the "Delay Start" timer has expired

Which gate combination would implement this logic?

  • (Door • Water) + (Start + Timer)
  • (Door • Water) • (Start + Timer)
  • (Door + Water) • (Start • Timer)
  • (Door + Water) + (Start • Timer)

Correct Answer: (Door • Water) • (Start + Timer)

Explanation: Let's break it down:

  • "Door is closed AND Water is available" requires AND gate: (Door • Water)
  • "Either Start button OR Timer" requires OR gate: (Start + Timer)
  • Both conditions must be true, so we need AND between them: (Door • Water) • (Start + Timer)

This ensures all safety and operational conditions are met before starting.

5.Which logic gate implements the Boolean expression: Y = A' + B' (where ' indicates NOT)?

  • AND Gate
  • OR Gate
  • NAND Gate
  • NOR Gate

Correct Answer: NAND Gate

Explanation: According to De Morgan's Theorem: A' + B' = (A • B)'. This is exactly the definition of a NAND gate. The NAND gate produces an output that is the inverse of the AND operation.

Key Insight: De Morgan's theorems help convert between AND/OR operations with inversions.

6.You see a logic gate symbol with the following characteristics:

  • Has two inputs
  • Has a small circle (bubble) at the output
  • Has a curved shape (like OR gate) with the bubble

What gate is this?

  • OR Gate
  • NOR Gate
  • AND Gate
  • NAND Gate

Correct Answer: NOR Gate

Explanation: A NOR gate is essentially an OR gate followed by a NOT gate. The small circle (bubble) at the output represents the inversion (NOT operation). The curved shape indicates it's based on an OR gate.

Memory Tip: NOR = NOT OR = OR gate with bubble at output.

7.For a three-input AND gate with inputs A, B, and C, when will the output be HIGH?

  • When at least one input is HIGH
  • When exactly one input is HIGH
  • When two inputs are HIGH
  • When all three inputs are HIGH

Correct Answer: When all three inputs are HIGH

Explanation: The AND gate follows the principle of logical conjunction. For an AND gate with any number of inputs, the output is HIGH only when ALL inputs are HIGH. For a 3-input AND: Y = A • B • C.

Application: Three-input AND gates are common in systems requiring multiple conditions to be true simultaneously.

8.What is the output of this gate combination: NOT gate → AND gate? The NOT gate takes input A and feeds into the AND gate along with input B.

  • Y = A' • B
  • Y = A • B
  • Y = A' + B
  • Y = A + B'

Correct Answer: Y = A' • B

Explanation: The NOT gate inverts input A to produce A'. This inverted signal (A') is then fed into the AND gate along with input B. The AND gate performs the logical AND operation between A' and B, giving us Y = A' • B.

Circuit Understanding: This combination creates a specific logical function that can be used in various digital circuits like enable/disable controls.

9. Which gate would you use to check if two binary numbers are equal?

  • AND Gate
  • OR Gate
  • XOR Gate
  • XNOR Gate

Correct Answer: XNOR Gate

Explanation: An XNOR gate outputs HIGH when both inputs are the same (both 0 or both 1). This makes it perfect for equality checking:

  • A=0, B=0 → Output=1 (equal)
  • A=0, B=1 → Output=0 (not equal)
  • A=1, B=0 → Output=0 (not equal)
  • A=1, B=1 → Output=1 (equal)

Application: XNOR gates are used in parity checkers and equality comparators.

10. Which of these is NOT a correct Boolean expression?

  • AND: Y = A • B
  • OR: Y = A + B
  • NAND: Y = A + B
  • XOR: Y = A ⊕ B

Correct Answer: NAND: Y = A + B

Explanation: The correct Boolean expressions are:

  • AND: Y = A • B
  • OR: Y = A + B
  • NAND: Y = (A • B)' or A • B with a bar over it
  • XOR: Y = A ⊕ B

Memory Tip: NAND = NOT AND, so it should have the AND expression with a NOT/inversion.

📝Key Takeaways

The Foundation

All digital systems are built from just 7 logic gates: AND, OR, NOT, NAND, NOR, XOR, XNOR

Universal Gates

NAND and NOR gates are "universal" - any digital circuit can be built using only one type of these gates

Truth Tables

Truth tables provide a complete description of a gate's behavior for all possible input combinations
