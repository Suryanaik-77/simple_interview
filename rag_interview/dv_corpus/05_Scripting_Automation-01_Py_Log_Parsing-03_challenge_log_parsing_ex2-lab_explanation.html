🧭 What this challenge is

The same python-in-the-loop flow, but a planted bug in the multiplier makes python (or the python-fed self-check) report failures. Read the report and fix the RTL.

🛠️ Debugging Guide
🔴 Symptom

Every vector fails - the design adds its inputs instead of multiplying them.

🔎 How to investigate
  1. Read any failing vector: prod equals a+b, not a*b.
  2. Open the design and read the expression.
  3. It uses + where it should use *.
🧭 Fix direction

Multiply the inputs: prod = a * b;

✅ Confirm

Re-run ./run.sh; python reports all vectors correct and the run ends with RESULT: TEST PASSED.
