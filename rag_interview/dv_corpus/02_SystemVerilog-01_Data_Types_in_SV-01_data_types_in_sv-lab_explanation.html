🧭 What this lab is

The reference lab pairs data_types_pkg, a package that typedefs the full range of SystemVerilog data types, with tb_Data_Types_in_SV.sv, a testbench that instantiates a data_types_demo DUT and declares example variables of each 2-state and 4-state type to show how they behave side by side.

💡 The concept

SystemVerilog splits scalar types into two families: 2-state types (bit, byte, shortint, int, longint) store only 0/1 and default to 0, making them compact and fast but blind to uninitialized or contended signals. 4-state types (logic, reg, integer, time) add X and Z states and default to X, which is essential for catching uninitialized-read bugs and modeling tri-state buses. Real number types (real, shortreal, realtime) and string round out scalar values, while typedef lets a package give these types meaningful, reusable names.

⚙️ How it works

data_types_pkg typedefs 2-state aliases (bit_t, byte_t, shortint_t, int_t, longint_t), 4-state aliases (logic_t, reg_t, integer_t, time_t), real aliases (real_t, shortreal_t, realtime_t), and string_t. tb_Data_Types_in_SV imports this package with import data_types_pkg::*;, drives clk/rst_n for the DUT, and instantiates data_types_demo with data_in, addr_in, valid_in, data_out, and valid_out ports declared as logic. Alongside the DUT connections, the testbench declares a set of 2-state test variables - test_bit, test_bit_vec, test_byte, test_ubyte (byte unsigned), test_shortint, test_int, test_uint (int unsigned), and test_longint - to exercise each type's range and signedness against the DUT's 4-state interface signals.

🎯 What you'll learn
  • Distinguishing 2-state (bit-family) from 4-state (logic/reg-family) types and when each is appropriate
  • Using typedef inside a package to give data types clear, reusable names
  • Declaring signed vs unsigned variants explicitly (e.g. byte unsigned, int unsigned)
  • Organizing related types into a package and importing them with import pkg::*
⚠️ Common mistakes
  • Using bit for a signal that needs to represent unknown/uninitialized or contended states, silently losing X/Z visibility
  • Forgetting the unsigned keyword on byte/int declarations and getting unexpected sign-extension in comparisons or arithmetic
