🧭 What this lab is

A seeded random test driven as a regression: run.sh compiles once and launches six seeded runs rolled up into a single pass/fail summary with a per-run CSV, then aggregates each run's verdict into a single pass/fail. It shows how a nightly regression is structured and scored.

⚙️ How it runs

The testbench reads +SEED, seeds $urandom, and self-checks against a reference. run.sh loops the seeds over one simv, greps each run's verdict, writes regr.log, and reports the roll-up. Guided passes every seed.

🎯 What you'll learn
  • Reuse one build across many seeded runs
  • Aggregate per-run verdicts into a regression summary
  • Reproduce a failing seed for triage
