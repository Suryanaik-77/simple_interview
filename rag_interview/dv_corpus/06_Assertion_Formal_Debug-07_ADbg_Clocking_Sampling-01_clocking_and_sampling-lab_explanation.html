🧭 What this lab is

A request/grant handshake whose correctness is checked by bound SystemVerilog Assertions, run dynamically under VCS -assert svaext. It shows how a failing assertion is read and traced back to the RTL.

💡 What this is

Concurrent SVA samples its expressions in the preponed region just before the clock edge, so a property clocked on the wrong signal or reading unsettled values behaves unexpectedly. This group checks the request/grant timing with sampled-value functions.

🔧 The properties
a_ack:    req |=> gnt          // grant follows request
a_nospur: gnt |-> $past(req)    // no grant without a request
+ one concept-specific property for this group
🎯 What you'll learn
  • Read a VCS SVA failure and map it to the offending property
  • Trace an assertion failure back to the RTL cause
  • Run assertions dynamically with -assert svaext

🧰 Tool & files

Engine: VCS -assert svaext (dynamic SVA). Files: adbg_clocking.sv (design), adbg_clocking_props.sv (bound SVA), tb_adbg_clocking.sv, run.sh. An extra sampled-value assertion a_sample uses $rose and $past to check timing at the clock edge.
