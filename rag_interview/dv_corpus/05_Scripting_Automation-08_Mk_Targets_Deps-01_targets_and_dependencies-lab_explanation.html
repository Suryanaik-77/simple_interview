🧭 What this lab is

A self-checking DUT whose Makefile expresses the flow as targets with prerequisites.

💡 The concept

Make reruns a target only when a prerequisite is newer; simulate depends on compile depends on sources.

⚙️ How it works

Run make and read the Makefile to see targets and prerequisites.

🎯 What you'll learn
  • Express a flow as make targets
  • Use prerequisites to avoid stale builds
  • Mark convenience targets .PHONY
🔧 Key constructs
target.PHONY
