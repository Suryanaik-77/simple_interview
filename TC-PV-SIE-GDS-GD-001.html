Problem Statement

GUIDED

FEOL fill (aes_cipher_top_FEOL.gds) and BEOL fill (aes_cipher_top_BEOL.gds) have been generated in previous steps. Before running DRC, antenna, or LVS, these fill GDS files must be merged with the original post-route GDS.

Your task: Run the provided merge script and verify that outputs/aes_cipher_top.fill.gds.gz is created.

📝 Step-by-Step Solution

  • Navigate and Start the Testcase

    The lab environment is already set up by setup_lab.sh. Navigate to the testcase directory and run the flow:

    cd ~/pd/labs/PV-SIE-GDS/TC-PV-SIE-GDS-GD-001
make all

  • Review the Merge Script

    Inspect the Tcl script to understand each step:

    cat scripts/merge_gds_block.tcl

    The script uses layout filemerge to combine FEOL fill, BEOL fill, and the base design GDS into a single compressed output. Confirm that feol_fill_gds and beol_fill_gds variables point to the correct input files.

  • Check the Log

    grep -i "error\|complete\|done" logs/merge_gds.log

  • Confirm Output GDS

    ls -lh outputs/aes_cipher_top.fill.gds.gz

  • Verify

    make verify

✅ Success Criteria

  • outputs/aes_cipher_top.fill.gds.gz exists and is non-empty
  • No errors in the merge log

🧪 Validation & Verification

🧠 Knowledge Assessment

1. Which calibredrv Tcl command is used to merge multiple GDS files in this lab?

  • gds::merge
  • layout filemerge
  • gds::open
  • layout merge
Correct! layout filemerge is the calibredrv command used to merge GDS files without loading the full layout GUI module.

2. In the merge script, what does layout peek $design_gds -topcell return?

  • The number of cells in the GDS
  • The name of the top-level cell in the GDS file
  • The file size of the GDS
  • A list of all layer names in the GDS
Correct! layout peek queries metadata from a GDS without fully loading it; -topcell extracts the top cell name, which is needed for the -createtop step.

3. The merged output GDS (aes_cipher_top.fill.gds.gz) is used as input for:

  • DRC, antenna check, and LVS runs
  • FEOL fill re-run
  • Standard cell placement
  • Clock tree synthesis
Correct! The merged fill GDS is the input for all sign-off checks (DRC, antenna, LVS).

4. Why does the script use a [pid]-based temporary file name (e.g., DM_feol.[pid])?

  • To compress the intermediate GDS automatically
  • It is required by the calibredrv filemerge syntax
  • To avoid collisions if multiple merge jobs run in parallel on the same machine
  • To enable hierarchical merging
Correct! Using the process ID makes the temp file name unique per run, preventing file conflicts when running concurrent jobs.
