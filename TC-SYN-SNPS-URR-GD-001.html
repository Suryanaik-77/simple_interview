Testcase 1: Missing RTL File Reference (Guided)

🏠 Lab Home / Testcase 1
📋 Type: Guided Exercise
⏱️ Estimated Time: 45-60 minutes

Problem Statement

GUIDED

You are working on synthesizing a digital design using Design Compiler. The top-level module is top_design, which instantiates several hierarchical submodules.

When you run the synthesis flow, Design Compiler produces the following warnings:

Warning: Design 'top_design' has '2' unresolved references. For more detailed information, use the "link" command. (UID-341)
Warning: Unable to resolve reference 'CKBD8BWP40P140LVT' in 'top_design'. (LINK-5)
Warning: Unable to resolve reference 'memory_controller' in 'top_design'. (LINK-5)

Your task: Investigate these warnings. One involves a missing RTL file in your filelist, and the other involves a missing cell definition in your library configuration.

🔍 Analysis

Design Compiler uses the 'link' command to assemble your design hierarchy, ensuring all instantiated modules and cells match their definitions. The error log above highlights two distinct failures in this process:

  • Missing RTL Module: The LINK-5 warning for memory_controller indicates that while top_design attempts to instantiate this module, the tool cannot locate its Verilog source code. This typically occurs when a file exists in your project directory but has not been added to your synthesis file list.
  • Missing Library Cell: The LINK-5 warning for CKBD8BWP40P140LVT signals that the synthesis tool cannot find the definition for this specific standard cell in your loaded technology libraries. This often points to a configuration issue where the required library database (.db file) is missing from your link_library variable.

Both of these issues prevent the design from completing its elaboration phase and must be resolved before synthesis can proceed.

📝 Step-by-Step Solution

  • Navigate and Start the Testcase

    You have already set up the lab directory structure using the provided setup guidelines. The required RTL files, scripts, libraries, and constraint files are now available in the testcase directory. With the lab environment ready, proceed with the following steps to run the synthesis.

    cd ~/pd/labs/SYN-SNPS-URR/TC-SYN-SNPS-URR-GD-001/
make all

  • Understand the Error Messages

    The warning LINK-5: Unable to resolve reference 'memory_controller' means Design Compiler has read the top_design module and found an instantiation of memory_controller, but it cannot find the definition of this module.

    This happens because:

      1) The file containing memory_controller was never read by DC

      2) DC searches through all previously read files and libraries

      3) When not found, it issues a LINK warning during the linking phase

  • Review Current Filelist Configuration

    Check the current design.filelist or the Tcl script that sets up RTL files:

    set rtl_files {../inputs/data_processing_unit.v
../inputs/interface_controller.v
../inputs/top_design.v
}

    Problem Identified: memory_controller.v is missing from the filelist!

  • Locate the Missing Source File

    Verify that the memory_controller.v file exists in the inputs directory by running a shell command directly from your tool prompt:

    dc_shell> sh ls ../inputs/ | grep memory_controller.v
memory_controller.v

    Explanation: We are searching the ../inputs/ directory because this is where all RTL source files for this testcase are provided. If the filename prints to the screen, the file is physically there — it just needs to be added to the filelist.

  • Add the Missing File to the Filelist

    Edit the design.filelist to include memory_controller.v:

    set rtl_files {../inputs/data_processing_unit.v
../inputs/interface_controller.v
../inputs/top_design.v
../inputs/memory_controller.v
}

    • Next: Now that we have resolved the missing RTL source file, we will tackle the second failure point. In the next step, we will correct the library configuration to resolve the LINK-5 and UID-341 errors related to missing standard cells.

  • Analyze Library Configuration

    The Warning: Unable to resolve reference 'CKBD8BWP40P140LVT' in 'top_design'. (LINK-5) indicates that the synthesizer cannot find this specific cell in the currently loaded technology libraries. The CKBD8...LVT naming convention suggests this is a Low Threshold Voltage (LVT) cell.

    Action: Review your synthesis script to identify missing library paths.

    # CURRENT CONFIGURATION (Incomplete)
set search_path [list . ../../pdk/stdcells/9T/hvt/lib/nldm ../../pdk/stdcells/9T/svt/lib/nldm ]
set target_library [list tcbn28hpcplusbwp40p140hvtssg0p81vm40c.db tcbn28hpcplusbwp40p140ssg0p81vm40c.db ]
set link_library [list * tcbn28hpcplusbwp40p140hvtssg0p81vm40c.db tcbn28hpcplusbwp40p140ssg0p81vm40c.db ]

    The script is missing the LVT library file path. You need to add the corresponding LVT search path to the search_path variable and include the LVT .db file in both target_library and link_library variables.

  • Correct and Update Library Paths

    Edit the scripts/run_synthesis.tcl file to include the LVT database files. This correction ensures the linker can resolve all standard cell references.

    # CORRECTED CONFIGURATION
set search_path [list . ../../pdk/stdcells/9T/hvt/lib/nldm ../../pdk/stdcells/9T/svt/lib/nldm ../../pdk/stdcells/9T/lvt/lib/nldm ]
set target_library [list tcbn28hpcplusbwp40p140hvtssg0p81vm40c.db \
                         tcbn28hpcplusbwp40p140ssg0p81vm40c.db \
                         tcbn28hpcplusbwp40p140lvtssg0p81vm40c.db ]

set link_library [list * tcbn28hpcplusbwp40p140hvtssg0p81vm40c.db \
                         tcbn28hpcplusbwp40p140ssg0p81vm40c.db \
                         tcbn28hpcplusbwp40p140lvtssg0p81vm40c.db ]

  • Exit Current Shell

    Before proceeding, ensure you have exited active tool shells. Type the following command to return to your main terminal.

    exit

  • Re-run Synthesis and Verify

    Now that you are back in the main shell, execute the synthesis flow using make run.

    make run

    After this, you should not see any linking issues.

📝 Knowledge Assessment

1. What is the primary purpose of the 'link' command in Design Compiler?

  • To compile the Verilog source code into binary.
  • To assemble the design hierarchy and verify that all modules and cells are defined.
  • To map logical gates to physical layout coordinates.
  • To generate the final GDSII file.
Correct! The link command checks the consistency of your hierarchy by ensuring every instantiated submodule or cell has a corresponding definition in your loaded files or libraries.

2. What does a LINK-5 warning regarding 'memory_controller' typically imply?

  • The module is too complex for the current technology node.
  • The RTL source file for the module was not included in the read filelist.
  • The memory controller is incompatible with the clock frequency.
  • The module name has a syntax error in the Verilog code.
Correct! LINK-5 means the tool can see the instantiation in your top-level file, but it cannot find the actual definition (source code) for that module.

3. Why did adding the LVT (Low Threshold Voltage) library to your configuration resolve the error for 'CKBD8BWP40P140LVT'?

  • It increased the synthesis speed.
  • It provided the definition for a specific standard cell missing from the previously loaded libraries.
  • It automatically corrected the timing constraints in the design.
  • It removed unnecessary hierarchy from the design.
Correct! Standard cells must be defined in the technology libraries (.db files). If a cell is referenced in the design but absent from the loaded link_library, the tool throws a resolution error.

4. If you fix an RTL filelist error, why must you re-run the synthesis flow?

  • To ensure the file size is correct.
  • To allow Design Compiler to re-elaborate the hierarchy with the newly included module.
  • To update the physical design files automatically.
  • The tool requires a reboot after every configuration change.
Correct! Elaboration happens early in the flow. If a module is missing at that stage, you must re-run the process so the tool can parse and build the design structure correctly.
