Problem Statement

GUIDED

You will perform Signal Net Routing for the tile in Cadence Innovus. Starting from the post-CTS database (tile_cts.odb), you will configure routing options, define and assign a Non-Default Routing Rule for clock nets, run global and detail routing, fix antenna violations, verify DRC and connectivity, and save the routed database.

This guided testcase includes the complete correct routing flow. Note that the CLK_NDR_RULE must be defined before it can be assigned — this is a common ordering mistake that the Challenge Testcase tests.

📄 Routing — Step-by-Step Command Explanation

  • Load the Post-CTS Database

    cd ~/pd/labs/PNR-CDN-RT/TC-PNR-CDN-RT-GD-001
make all

    Source the routing script:

    source ../scripts/routing.tcl

    The script starts by loading the post-CTS database:

    read_db ../inputs/tile_cts.db

set design_name tile
    Note: This testcase uses the .odb (OpenDB) format — Innovus's native binary database format. Both .db and .odb are valid Innovus database formats; .odb is more compact and faster to read/write.

  • Set Routing Options

    Configure three key routing engine parameters before routing begins:

    Parameter Description
    route_design_antenna_insertion_max_loops 10Maximum iterations for antenna repair during detail routing — the router retries antenna-violating paths up to 10 times.
    route_design_with_si_driven trueEnable Signal Integrity (SI) driven routing — the router avoids parallel routing patterns that cause excessive crosstalk noise on critical timing paths.
    route_design_concurrent_minimize_via_count_effort highMinimize via count during routing with high effort — reduces net RC delay on critical paths by reducing via resistance and capacitance.
     
    set_db route_design_antenna_insertion_max_loops 10
set_db route_design_with_si_driven true
set_db route_design_concurrent_minimize_via_count_effort high

  • Define the Clock NDR Rule

    What it does: Creates a Non-Default Routing Rule named CLK_NDR_RULE that specifies wider metal and increased spacing on M4 for clock net segments. This rule must be defined before it can be assigned to any nets.

    create_route_rule -name CLK_NDR_RULE -width {M4 0.4} -spacing {M4 0.4}
    Why define the rule before assignment? In Innovus, NDR rules are named objects that must exist in the database before they can be referenced. The assign_route_rules command looks up the rule by name — if the rule does not exist yet, the assignment fails with an error. Always call create_route_rule before assign_route_rules.

  • Assign NDR to Clock Propagated Nets

    What it does: Assigns the CLK_NDR_RULE to all propagated clock nets. Propagated nets are the nets that Innovus uses to physically route the clock tree — these are the nets that carry the clock signal from the source through all CTS buffers to the flip-flop clock pins.

    assign_route_rules \
    -non_default_rule CLK_NDR_RULE \
    -nets [get_db [get_db clocks *] .propagated_nets]
    [get_db [get_db clocks *] .propagated_nets] retrieves all nets that belong to the propagated clock network — these are the nets that will receive 2x spacing and 2x width on M4 during detail routing.

  • Run Global Routing (route_global)

    What it does: Assigns all signal nets to routing channels at the G-cell (global routing cell) granularity. This step establishes the overall routing topology — which net goes through which routing region — without yet committing exact track assignments. Global routing is fast and identifies congestion hotspots before detail routing begins.

    route_global -effort medium
    What to check: Global routing congestion map in the Innovus GUI. Red hotspots indicate regions where more nets need routing tracks than are available — these regions may cause detail routing failures if not addressed (by adjusting placement or relaxing routing rules).

  • Run Detail Routing (route_detail)

    What it does: Completes the exact wire and via assignments for every net, respecting all DRC rules (minimum width, minimum spacing, enclosure, antenna). This is the most computationally intensive step in the routing flow — it assigns every track and via to complete the physical connections.

    route_detail -effort medium
    What to check: DRC violation count printed at the end of route_detail. Zero violations is ideal but rarely achieved on the first pass for complex designs — antenna violations and a small number of DRC errors are common and are fixed in the next steps.

  • Fix Antenna Violations (route_fix_antenna)

    What it does: Iteratively fixes antenna violations introduced during detail routing. For each violating net, Innovus either inserts a diode (antenna protection cell) at the gate input or modifies the routing to add a via that breaks the antenna length by jumping to a higher metal layer.

    route_fix_antenna
    What to check: Antenna violation count before and after — should drop to near zero. Any remaining antenna violations after route_fix_antenna require manual intervention (usually by increasing the max loops parameter or adjusting antenna diode availability).

  • Verify DRC and Connectivity

    verify_drc > ../reports/route_drc.rpt
    What to check: Total DRC violation count. Zero errors confirms the routed design is fully DRC-clean. Any remaining violations must be resolved before tape-out. 
    verify_connectivity -type all > ../reports/connectivity.rpt
    What to check: No open nets (nets with unconnected pins) and no short circuits (unintended connections between different nets). Both open and short connectivity errors are critical failures. 
    report_route_drc > ../reports/drc_summary.rpt
    What to check: Categorized DRC summary — shows counts by rule type (spacing, width, antenna, enclosure). Use this to identify which rule categories have remaining violations.

  • Save the Routed Database

    write_db ../outputs/${design_name}_routed.db
    The routed database is saved as tile_routed.db. This is the input to chip finishing (metal fill, sign-off DRC/LVS, timing sign-off with extracted parasitics).

✅ Success Criteria

Routing is complete when ALL of the following are true:

  • CLK_NDR_RULE created and assigned to all clock propagated nets before routing
  • route_global completes with acceptable congestion (no overflowed G-cells)
  • route_detail completes with 0 or minimal DRC violations
  • route_fix_antenna resolves all antenna violations
  • ../reports/route_drc.rpt — 0 DRC violations
  • ../reports/connectivity.rpt — 0 opens, 0 shorts
  • ../outputs/tile_routed.db exists on disk

📚 Knowledge Assessment Quiz

1. The antenna effect is a manufacturing reliability issue that occurs during chip fabrication. What is the physical mechanism that causes it?

  • High current through metal wires during electrostatic discharge events damages the gate oxide of nearby transistors
  • Thermal stress during metal deposition causes metal atoms to migrate toward transistor gates, reducing their oxide thickness
  • During plasma etching of metal layers, ions in the plasma bombard exposed metal surfaces. Long floating metal segments act like antennas, accumulating this charge. If the accumulated charge has no other discharge path, it tunnels through the thin gate oxide of any connected transistor, permanently damaging it
  • Voltage spikes during testing of finished wafers break down gate oxide when test vectors exercise long interconnect paths
Correct! During wafer fabrication, plasma etching processes are used to pattern metal layers. The plasma contains ionized particles that continuously bombard the wafer surface. A long metal wire connected only to a gate input (with no other discharge path) acts as a charge collector — it accumulates plasma charge proportional to its area. When accumulated charge density becomes too high, it discharges through the only available path: the thin gate oxide of the connected transistor. This gate oxide damage is permanent and can make the transistor non-functional, reducing manufacturing yield. Advanced nodes are more susceptible because thinner gate oxides have lower breakdown charge.

2. How do routing tools detect and quantify antenna violations?

  • By measuring the electrical resistance of each routed wire — high resistance indicates dangerously long antenna exposure
  • By counting the number of vias on each net — more vias mean the signal passes through more etch steps, accumulating more charge
  • By calculating the Antenna Ratio = Metal Area (of the floating segment below the via connecting to the gate) / Gate Oxide Area (of the connected transistor gate). If this ratio exceeds the foundry-specified limit, the net has an antenna violation
  • By comparing wire width to minimum width rules — wires wider than 2× minimum are flagged as antenna risks due to excess charge collection area
Correct! Antenna Ratio = Metal Area / Gate Area. The metal area represents the exposed charge-collecting surface during etching of that layer. The gate area determines how much charge can be safely absorbed before oxide breakdown. Foundries specify a maximum allowable antenna ratio for each metal layer in their process design rules. For example, if M3 has a maximum antenna ratio of 400:1, a M3 segment of 400 µm² can safely connect to a gate of 1 µm² area. Exceeding this ratio means the accumulated charge during M3 etching can damage that gate. The router checks every net's geometry against these foundry-specified limits.

3. Layer jumping (layer hopping) is one of two common antenna fixing techniques. How does it reduce the antenna ratio?

  • Layer jumping inserts a short wire segment on M1 near the gate, providing a low-resistance ground path that drains accumulated charge safely
  • Layer jumping reroutes the wire to a higher metal layer where the foundry permits larger antenna ratios due to thicker oxide protection
  • Layer jumping inserts a via to a higher metal layer partway along the long wire, breaking the continuous lower-layer metal segment into a shorter segment. The charge that accumulated on the lower-layer portion before the via is now discharged through the upper layer when that layer's routing connects to a diffusion node (source/drain). The shorter lower-layer segment has less area, giving a lower antenna ratio
  • Layer jumping routes an identical copy of the wire on a different layer in parallel, and the two copies share the accumulated charge, halving the effective antenna ratio per layer
Correct! Metal layers are processed sequentially from M1 upward. At the moment M3 is being etched, M1 and M2 have already been connected to diffusion nodes (which provide discharge paths). By inserting a via from M3 to M4 partway along the long M3 segment — before the problematic area accumulates too much charge — the charge on that M3 segment can drain through M4 down to M2 down to M1 down to a diffusion node that was connected at a lower layer. The key constraint is that layer jumps go up (not down) because lower layers are already processed and cannot receive new vias during upper-layer etching steps.

4. What are the three main stages of the routing flow, in order?

  • Track assignment → Global routing → Detailed routing → Search and Repair
  • Detailed routing → Global routing → Track assignment
  • Global routing → Track assignment → Detailed routing (followed by Search and Repair for DRC fixing)
  • Global routing → Detailed routing → Via optimization → Track assignment
Correct! Routing proceeds in three stages: (1) Global routing — coarse routing that assigns each net to routing regions (bins) without specifying exact wire geometry; determines routing paths and identifies congested areas; (2) Track assignment — assigns specific routing tracks (exact wire positions on each metal layer) to each global route segment, resolving track conflicts; (3) Detailed routing — performs exact wire shaping, via insertion, and DRC-clean geometry for every net. After detailed routing, Search and Repair (S&R) iteratively finds and fixes remaining DRC violations. Each stage refines the previous: global routing plans routes, track assignment places them on tracks, detail routing makes them DRC-legal.
