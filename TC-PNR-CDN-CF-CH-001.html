🧠 Knowledge Assessment

1. Physical netlist and logical netlist are two distinct outputs from chip finishing. What is the key difference between them?

  • Physical netlist uses RTL-level constructs; logical netlist uses gate-level primitives — physical is read by synthesis, logical by PnR
  • Physical netlist includes routing wire lengths; logical netlist only has cell connectivity without parasitic information
  • Physical netlist (also called LVS netlist) includes all instances in the design — standard cells, macros, AND physical-only cells (endcap, welltap, filler, tie cells, decap). Logical netlist excludes all physical-only cells and represents only the functional logic. LVS uses the physical netlist; LEC (equivalence checking) uses the logical netlist
  • Physical netlist is in Verilog format; logical netlist is in SPICE format — the difference is only the file syntax, not the cell content
Correct! The distinction is critical because each downstream tool needs a different view: LVS (Layout-versus-Schematic) compares the GDS layout against all physical instances — it must see the physical netlist including filler/endcap/welltap/tie cells because those are real transistor-containing devices in the layout. If LVS used only the logical netlist, it would report thousands of "extra" devices for every physical-only cell. LEC (Logical Equivalence Checking) verifies that the final placed-and-routed netlist is functionally equivalent to the original RTL — it must use the logical netlist that excludes physical-only cells, because those cells have no functional counterpart in the RTL.

2. DRC and LVS are both physical verification checks run on the GDS. What does each one verify?

  • DRC checks that cell timing meets the target frequency; LVS checks that the layout matches the floorplan
  • DRC checks that all metal layers have sufficient density; LVS checks that via connections are mechanically sound
  • DRC (Design Rule Check) verifies that all geometric shapes in the GDS comply with the foundry's manufacturing rules — minimum width, spacing, enclosure, and density rules. LVS (Layout-versus-Schematic) extracts the electrical connectivity from the GDS and verifies it matches the reference schematic (netlist) — checking for missing connections, extra connections, and incorrect device parameters
  • DRC checks that the design meets power consumption targets; LVS checks that voltage domains are correctly partitioned in the layout
Correct! DRC and LVS are complementary but verify entirely different aspects: DRC ensures the layout is physically manufacturable — if any polygon is too narrow, too close to a neighbor, or violates an enclosure rule, that location may not print correctly on the wafer or may short/break after fabrication. LVS ensures the layout is electrically correct — extracting all transistors and their connections from the GDS and comparing them to the expected netlist to confirm the circuit is connected as intended. A design must pass both DRC (physical correctness) and LVS (electrical correctness) before tape-out. They are both run by tools like Calibre on the final merged GDS.

3. Electromigration (EM) is a reliability failure mechanism in metal interconnects. What causes it?

  • Electromigration is caused by excessive voltage across a wire, which breaks the dielectric barrier between adjacent metal layers
  • Electromigration is caused by thermal expansion mismatches between metal and dielectric during temperature cycling, cracking the wire
  • Electromigration is caused by high current density in a metal wire. Electrons flowing through the wire transfer momentum to metal atoms, gradually displacing them in the direction of electron flow. Over time, this creates voids (opens) where metal atoms left and hillocks (shorts) where they accumulated
  • Electromigration is caused by parasitic inductance in long wires creating current spikes that locally melt the metal at the inductance peak
Correct! Electromigration (EM) is a gradual metal degradation mechanism driven by current density (current per unit cross-sectional area, measured in mA/µm²). When electrons carry enough momentum to displace metal atoms, those atoms migrate in the direction of electron flow. The empty spots left behind form voids that eventually disconnect the wire (open circuit failure). The excess atoms pile up at barriers like grain boundaries or vias, forming hillocks that can short-circuit to adjacent wires. EM failure is time-dependent — it may take years at normal operating conditions, but the foundry specifies maximum allowed current density per metal layer and via to guarantee a specified device lifetime (e.g., 10 years at 125°C). EMIR sign-off verifies these limits are not exceeded.

4. EMIR analysis distinguishes between static IR drop and dynamic IR drop. What is the difference and which one causes hold violations?

  • Static IR drop occurs only at chip startup; dynamic IR drop occurs during normal operation — both affect only setup timing
  • Static IR drop is the average voltage drop; dynamic IR drop is the peak drop — both affect setup timing only, never hold
  • Static IR drop is the DC voltage drop from average current draw — it is constant and can create setup violations by slowing all cells in a region. Dynamic IR drop is the instantaneous voltage droop caused by peak switching activity — it is transient but larger in magnitude and can specifically cause hold violations on clock capture paths when the supply droops during a clock edge
  • Static IR drop is measured before placement; dynamic IR drop is measured after routing — static is always larger than dynamic
Correct! Static IR drop = R × I_average. It creates a constant voltage reduction that slows all cells in the affected region, potentially causing setup violations on data paths driven from those cells. Dynamic IR drop = R × I_peak, occurring during peak switching events (e.g., when a large block comes out of reset and all flip-flops switch simultaneously). The instantaneous voltage droop is larger than static IR drop and is transient. If this droop affects the clock distribution cells on the capture path of a flip-flop, the clock edges arrive later — which can create hold violations because the data (from the launch flip-flop that did not experience the droop) arrives too early relative to the delayed capture clock. Dynamic IR drop → hold violations is a critical, non-obvious sign-off concern.
