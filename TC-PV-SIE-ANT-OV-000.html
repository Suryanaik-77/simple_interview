📚 Background: Antenna Effects

During plasma etching steps in IC fabrication, charges accumulate on exposed metal conductors. These charges can discharge through the thin gate oxide of connected transistors, causing permanent damage (gate oxide breakdown or threshold shift). This is called the antenna effect.

To prevent this, foundries define antenna ratio rules: the ratio of the exposed metal area to the connected gate area must stay below a maximum limit. In TSMC 28nm, separate ratios apply to each metal layer.

Calibre antenna check uses the same DRC engine with a specialized antenna rule deck. The runset is structurally identical to DRC:

LAYOUT PATH "../inputs/aes_cipher_top.fill.gds"
LAYOUT PRIMARY "aes_cipher_top"
LAYOUT SYSTEM GDSII

DRC SUMMARY REPORT "aes_cipher_top.antenna.summary"
DRC RESULTS DATABASE "../outputs/aes_cipher_top.antenna.results" ASCII

INCLUDE "/efs/semicon_labs_pd/pdk/.../CLN28HP_9M.ANT_002.14a"

The only difference from DRC is the INCLUDE path, which must point to the antenna rule deck, not the DRC or fill deck.

🧠 Knowledge Check

1. The antenna effect damages which transistor structure?

  • Source/drain diffusion regions
  • Gate oxide
  • Metal contacts
  • Substrate well regions
Correct! Plasma charges discharge through the gate oxide, damaging or destroying it.

2. The antenna ratio is defined as:

  • Gate area / metal area
  • Metal (conductor) area / connected gate oxide area
  • Via area / metal area
  • Poly area / diffusion area
Correct! A high metal-to-gate ratio means more charge can accumulate per unit of gate, increasing damage risk.

3. Which TSMC 28nm rule deck file is used for the antenna check?

  • calibre.drc
  • Dummy_Metal_Via_Calibre_28nm.13a
  • CLN28HP_9M.ANT_002.14a
  • calibre.lvs
Correct! The antenna rule deck is a separate file from the DRC and fill decks.

4. How can antenna violations be fixed in the P&R flow?

  • Re-run CTS
  • Insert antenna diodes near affected gates or reroute signals through lower metal layers
  • Increase power supply voltage
  • Add more fill metal
Correct! Diode insertion provides a discharge path; rerouting breaks the long conductor that accumulates charge.
