📖 Theory and Background

What is Synthesis?

Synthesis is the process of converting your RTL design (written in Verilog or SystemVerilog) into a gate-level netlist — a circuit built from real standard cells selected from a technology library (e.g., TSMC 28 nm). The synthesis tool simultaneously optimises for Power, Performance, and Area (PPA) while meeting the timing constraints you provide.

Think of it this way: RTL describes what the design should do; synthesis decides how to build it using actual logic gates that can be fabricated on silicon.

The Three Inputs Synthesis Needs

Input File Type What it contains
RTL Files .v / .sv Your design described in Verilog or SystemVerilog
Technology Library .lib Describes all available standard cells — their speed, power, and area
Timing Constraints .sdc Specifies clock frequency and required signal arrival times at ports

The Synthesis Stages in Genus

Genus runs synthesis in a well-defined sequence of stages:

Stage What it does
Load Libraries Tells Genus which standard cells and macros are available. Without this the tool has nothing to map onto.
Read RTL Reads Verilog/SystemVerilog source files into memory. Checks for parse errors.
Elaborate Connects all modules together and builds the full design hierarchy in memory.
Generic Synthesis Converts RTL into a technology-independent logic network. Clock gating cells are also identified here.
Mapping Maps the generic logic onto actual standard cells from your .lib files.
Optimization Fixes remaining timing violations by swapping cells for faster versions or inserting buffers.
Write Outputs Saves the gate-level netlist, updated SDC, and full synthesis database for downstream tools.

Standard Cell Threshold Voltages (HVT / SVT / LVT)

TSMC 28 nm provides cells in three threshold-voltage (Vt) flavors. Each has a different speed-versus-leakage trade-off:

FlavorNaming suffixSpeedLeakageTypical use
HVT (High Vt)hvt…SlowerLowDefault cells; good for power budget
SVT (Standard Vt)ssg…MediumMediumGeneral-purpose standard cells
LVT (Low Vt)lvt…FasterHighCritical paths only; excluded by default to control leakage
Lab Focus: In this lab you load all three library flavors but use set_dont_use to block LVT and clock-tree cells during logic synthesis. This keeps static power low. Genus will only reach for those cells if a timing path truly cannot close with HVT/SVT cells.

Logic-Aware Synthesis and Clock Gating

“Logic-aware synthesis” refers to Genus’s ability to optimise the design not just structurally (gate swapping) but by understanding the logical intent of the RTL. One key feature enabled in this lab is clock gating insertion (set_db lp_insert_clock_gating true).

Clock gating stops the clock from toggling flip-flops that are not changing value. This is one of the most effective techniques for reducing dynamic power in a digital design — typically reducing clock power by 20–40%.

This attribute must be set before elaborate so that Genus identifies gating opportunities when it analyses the design structure.

🧠 Knowledge Assessment

1. What does syn_map do that syn_generic does not?

  • A. It reads the RTL source files into Genus memory.
  • B. It inserts clock gating cells to reduce dynamic power.
  • C. It replaces the generic logic network with actual standard cells from the technology library.
  • D. It writes the final gate-level netlist to a Verilog file.
Correct! syn_generic creates a technology-independent logic network. syn_map then replaces those generic gates with real cells from the loaded .lib files, picking the best cell to meet timing and area goals.

2. Why should you use the output design.sdc for place-and-route instead of the original SDC?

  • A. The original SDC is deleted by Genus after synthesis.
  • B. Synthesis adds new clocks (such as clock gating cell outputs) not present in the original SDC; the output SDC captures these additions.
  • C. The output SDC uses a format required exclusively by Innovus.
  • D. The output SDC is smaller in size and loads faster.
Correct! When synthesis inserts clock gating cells, Genus creates derived clocks for them. write_sdc exports an updated SDC that includes these new clocks, giving place-and-route the complete and accurate timing picture.

3. Why must set_db lp_insert_clock_gating true be set before elaborate?

  • A. Elaboration reads the library files which need clock gating enabled first.
  • B. Genus identifies clock gating opportunities during elaboration, so the setting must be active before that step.
  • C. Clock gating cells are inserted during read_hdl, before elaborate runs.
  • D. The setting has no effect if applied after libraries are loaded.
Correct! Genus analyses the design for clock gating candidates during elaboration. Setting this attribute beforehand ensures those opportunities are captured when syn_map inserts ICG cells.

4. Which of the following is NOT a required input for synthesis?

  • A. RTL source files (.v / .sv)
  • B. Technology library (.lib)
  • C. Timing constraints (.sdc)
  • D. A placed floorplan (.def)
Correct! A placed floorplan (.def) is an input for place-and-route, not synthesis. Synthesis only needs RTL source files, the technology library, and timing constraints.
