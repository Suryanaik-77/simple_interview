4. Analyze Check timing Warnings and Fix Constraints

From the above check_timing report, several timing intent warnings were observed. Each warning indicates a missing or incomplete timing constraint in the SDC file. The following steps explain how to resolve each warning using the appropriate SDC command.

1.The following end-points are not constrained for maximum delay

In the above Check timing report, the warning "The following end-points are not constrained for maximum delay" indicates that some registers are not getting clock signals, This indicates that clock is not defined in the SDC file. Before going to create a clock we need to find clock ports first, for that we need to go from register clock pin side, Means the port which is driving the clock pin of a register is the clock port. For that we need to use all_fanin command

step1: From the above report take any one pin, and find clock the pins

Note : if remove the word from last / the remaining name is cell name we are using cell name to get the clock pins

eg: pin_name : rn1_reg[7]/next_state

cell_name : rn1_reg[7]

The below command will return the clock pin of register 

dc_shell> get_pins -filter "is_clock_pin ==  true" -of [get_cells rn1_reg[7]]
{rn1_reg[7]/clocked_on}

Now we need to do all_fanin command for that clock pin to find the driver port 

dc_shell> all_fanin -to [get_pins {rn1_reg[7]/clocked_on}] -startpoints_only -flat
{clk}
Now for this port create clock using the command create_clock 
create_clock -name clk -period 1 [get_ports clk]

2. Inputs without clocked external delays

In the above Check timing report, the warning "The following input ports have no clock_relative delay specified, the command set_input_delay without -clock option will be ignored. (TIM-216) " indicates that input ports do not have timing relationships defined relative to a clock.

To clear the above issue, define input delays using the set_input_delay command. 

set_input_delay [expr 1*0.6] -clock clk [get_ports [remove_from_collection [all_inputs] {clk clk_new_1 clk_new_2} ]]
set_input_delay [expr 2.2*0.6] -clock clk1 [get_ports [remove_from_collection [all_inputs] {clk clk_new_1 clk_new_2} ]]
set_input_delay [expr 4.3*0.6] -clock clk2 [get_ports [remove_from_collection [all_inputs] {clk clk_new_1 clk_new_2} ]]

5.The following end-points are not constrained for maximum delay

In the above Check timing report, the warning "The following end-points are not constrained for maximum delay" indicates that the tool reported that some flops are not clocked.

To clear the above issue, We need to find the which clock is driving those flops Take any one pin reported in the above report from that find the clock pin of that flop using get_pins 

dc_shell> get_pins -filter "is_clock_pin" -of  [get_cells rd0_reg[0]]
{rd0_reg[0]/clocked_on}

Now we need to find the fanin to that clock pin which will helps to find the clock start point the all_fanin command. 

dc_shell> all_fanin -to [get_pins {rd0_reg[0]/clocked_on}] -startpoints_only -flat 
{U2/**logic_0** clk_div_reg/clocked_on}
By observing the outputs we can observe that one of the pin is Divider circuit pin , from that we can understand that there might be Generated clock is present for to find source of divider circuit we need to do the fanin for the divider circuit clock pin

Use all_fanin command. 

dc_shell> all_fanin -to clk_div_reg/clocked_on -startpoints_only -flat 
{clk}
Now we got the source of generated clock now create generated clock using create_generated_clock command. 
create_generated_clock -name gen_clk -source [get_ports clk] -divide_by 2 [get_pins clk_div_reg/Q]

5. Outputs without external load

"Outputs without external load" indicates that the tool does not know the capacitive load seen by output ports.

specify the output load capacitance using the set_load command. 

set_load 0.05 [all_outputs]

6. Inputs without external driver/transition

Without driver/transition for input ports, the tool cannot accurately model input signal transition characteristics.

To clear the above issue, specify the driving cell using the set_driving_cell command. 

dc_shell> get_lib_cells */BUFFD8*HVT
{tcbn28hpcplusbwp40p140hvtssg0p81vm40c_ccs/BUFFD8BWP40P140HVT}
dc_shell> set_driving_cell -lib_cell BUFFD8BWP40P140HVT [all_inputs] -no_design_rule

Since both clocks can potentially reach the same register clock pin through the mux, the tool reports that multiple clock waveforms are driving the same sequential clock pin.

However, only one clock is active at a time depending on the control signal, so this is expected behavior and these warnings can be ignored.

After reviewing these warnings and confirming their expected behavior, the timing constraints can be considered valid for this design.

🧠 Knowledge Assessment Quiz

Question 1: Which warning is reported when input ports are not constrained with respect to a clock?

  • A. Sequential clock pins with multiple clock waveforms
  • B. Inputs without clocked external delays
  • C. Outputs without external load
  • D. Generated clocks missing

Correct! This warning appears when input ports do not have timing relationships defined relative to a clock.

Question 2: Which SDC command correctly constrains input ports to remove the warning "Inputs without clocked external delays"?

  • A. set_input_delay -clock clk <input_delay> [get_ports data_in]
  • B. set_output_delay -clock clk <output_delay> [get_ports data_in]
  • C. create_clock -name clk -period <period> [get_ports data_in]
  • D. set_clock_uncertainty -setup <uncertainty> [get_clocks clk]

Correct! The set_input_delay command specifies the arrival time of external signals relative to a clock.

Question 3: Which warning appears if a generated clock is not defined in the SDC constraints?

  • A. Inputs without clocked external delays
  • B. Outputs without external load
  • C. Sequential clock pins without clock waveform
  • D. Nets with multiple drivers

Correct! This warning occurs when the design contains derived clocks but they are not defined using create_generated_clock.

Question 4: Which SDC command correctly defines a generated clock derived from another clock?

  • A. create_generated_clock -name gen_clk -source [get_ports clk] -divide_by 2 [get_pins divider/Q]
  • B. create_clock -name gen_clk -period <period> [get_ports clk]
  • C. set_clock_uncertainty -setup <uncertainty> [get_clocks clk]
  • D. set_input_delay -clock gen_clk <delay> [get_ports data]

Correct! The command create_generated_clock defines clocks that are derived from another clock source.

Question 5: Which warning occurs when output ports do not have load capacitance defined?

  • A. Inputs without clocked external delays
  • B. Outputs without external load
  • C. Generated clocks missing
  • D. Timing exceptions with no effect

Correct! This warning occurs when output ports do not have load capacitance defined for timing analysis.

Question 6: Which SDC command correctly constrains output ports with load capacitance?

  • A. set_input_delay -clock clk <delay> [get_ports data_out]
  • B. set_load <capacitance> [get_ports data_out]
  • C. set_output_delay -clock clk <delay> [get_ports data_out]
  • D. set_driving_cell -lib_cell BUFFD4BWP40P140HVT [get_ports data_out]

Correct! The set_load command specifies the external capacitance seen by output ports.
