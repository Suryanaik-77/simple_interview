📚 Background: BEOL Dummy Fill

After FEOL fill establishes OD/PO density, the metal stack also requires density balancing. Metal fill (BEOL fill) inserts floating metal and via shapes into each routing layer to satisfy the foundry's pattern-density design rules for CMP.

For TSMC 28nm 1P9M, layers M1 through M9 and via cuts V1–V8 all require minimum density. The BEOL fill rule deck (Dummy_Metal_Via_Calibre_28nm.13a) computes the required fill per layer and outputs a fill GDS containing only the new shapes.

Key runset statement differences from FEOL fill:

  • Output is named aes_cipher_top_BEOL.gds (distinct from the FEOL output)
  • INCLUDE points to the Metal/Via rule deck, not the OD/PO deck
  • #DEFINE UserprBoundary is still required

🧠 Knowledge Check

1. Which PDK file is used for TSMC 28nm BEOL metal fill?

  • Dummy_OD_PO_Calibre_28nm_HP.13a
  • Dummy_Metal_Via_Calibre_28nm.13a
  • calibre.drc
  • CLN28HP_9M.ANT_002.14a
Correct! The BEOL fill deck targets Metal and Via layers, distinct from the FEOL OD/PO fill deck.

2. What happens if #DEFINE UserprBoundary is missing from the BEOL runset?

  • Calibre aborts immediately
  • Calibre generates FEOL fill instead
  • Fill may extend beyond the intended boundary region
  • The output GDS is not created
Correct! Without the boundary define, the fill algorithm does not recognize the chip boundary layer and may fill unintended areas.

3. Why must FEOL fill be run before BEOL fill?

  • OD/PO density must be established before metal stack density is computed
  • Calibre cannot load both rule decks in one session
  • BEOL fill requires the FEOL GDS as its layout input
  • There is no ordering requirement
Correct! The BEOL density check accounts for OD patterns in its computations, so FEOL must exist first.

4. The BEOL fill output GDS contains:

  • The original layout merged with fill shapes
  • Only the new fill shapes (to be merged separately)
  • DRC violation markers
  • A flattened copy of the original design
Correct! The fill run outputs only the fill shapes. A separate merge step combines them with the original layout.
