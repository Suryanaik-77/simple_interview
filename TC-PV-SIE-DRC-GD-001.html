🧠 Knowledge Assessment

1. In the DRC runset, LAYOUT PATH must point to:

  • The original post-route GDS before fill
  • The fill-merged GDS (aes_cipher_top.merged_fill.gds)
  • The FEOL fill GDS only
  • The LEF/DEF representation
Correct! DRC must check the complete layout including fill shapes.

2. Where does Calibre write DRC violation locations?

  • Only in the summary report
  • In the DRC RESULTS DATABASE file (ASCII text with coordinates)
  • In the Calibre log file
  • In a separate GDS file
Correct! The results database contains violation rule names and coordinates for each error.

3. What does DRC MAXIMUM RESULTS 50 mean?

  • Run at most 50 DRC rules
  • Write at most 50 violations to the results database per rule
  • Use at most 50 CPU threads
  • Limit run to 50 minutes
Correct! It limits output per rule, not the total check count.

4. Which Calibre flag enables multi-threaded DRC for large designs?

  • -turbo N (where N is thread count)
  • -parallel N
  • -threads N
  • -mp N
Correct! -turbo N enables N-threaded parallel processing in Calibre.
