🧠 Knowledge Assessment

1. If you use FFG (fast) timing libraries but annotate a cworst (worst parasitic) SPEF, what happens?

  • PrimeTime will automatically correct the mismatch.
  • The results are physically meaningless because fast cells with worst-case parasitics do not represent any real operating condition.
  • The analysis will fail with an error.
  • It produces the same result as using matched inputs.
Correct! Libraries and SPEF must match the same PVT corner. Fast libraries model fast transistors at high voltage; they should be paired with cbest/rcbest SPEF (minimum parasitics) for hold analysis. Mismatched pairs give unreliable slack values.

2. Why are both cworst and rcworst needed for setup analysis?

  • They are interchangeable; only one is needed.
  • Cworst maximizes coupling capacitance (worst crosstalk effects) while rcworst maximizes both resistance and capacitance (worst RC delay). Different nets may be critical under different extraction conditions.
  • Cworst is for hold analysis and rcworst is for setup analysis.
  • They only differ in file format, not parasitic values.
Correct! Cworst and rcworst stress different aspects of the parasitics. Some critical paths may be dominated by coupling (cworst catches them), while others are dominated by wire RC (rcworst catches them). Running both ensures no setup violation is missed.

3. What does parasitic annotation do in PrimeTime?

  • It replaces the gate-level netlist with a transistor-level netlist.
  • It adds clock tree buffers to the design.
  • It maps the extracted R, C, and Cc values from the SPEF onto every net in the design, replacing wire-load model estimates with real physical parasitic data.
  • It generates the floorplan DEF file.
Correct! Annotation overlays real extracted parasitics onto the logical netlist. After annotation, PrimeTime uses these real R and C values to compute accurate net delays and transitions instead of estimates.

4. For a complete signoff, how many PT sessions are typically needed?

  • 1 session at typical corner is sufficient.
  • 2 sessions: one slow, one fast.
  • At minimum 4 sessions covering slow and fast process at both temperature extremes, each with its matching RC extraction SPEF.
  • The number depends only on the number of clocks in the design.
Correct! Signoff requires checking setup at slow corners (SS + cworst/rcworst) and hold at fast corners (FF + cbest/rcbest), at both temperature extremes. This gives at minimum 4 sessions to ensure timing closure across all operating conditions.
