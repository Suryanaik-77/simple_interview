📚 Knowledge Assessment Quiz

1. What is the purpose of the NDM (New Data Model) in ICC2?

  • It stores the final GDS layout for tape-out submission
  • It is ICC2's unified library format that holds both the physical (layout) views and timing views of a cell in a single database
  • It defines the metal stack and design rules for the target process node
  • It contains the RTL description of the design before synthesis
Correct! The NDM (New Data Model) is ICC2's native library format. It replaces the separate .lef/.lib/.db files used by older tools by combining physical views (cell boundaries, pin locations, routing obstructions) and timing views into one unified database that ICC2 reads directly.

2. What does MMMC stand for and why is it used in physical design?

  • Multi-Module Multi-Cell — it allows the same cell to be used in different modules simultaneously
  • Maximum Metal Minimum Capacitance — it describes the parasitic extraction model for routing layers
  • Multi-Mode Multi-Corner — it allows ICC2 to simultaneously analyze timing across all operating conditions (different clock modes and PVT corners) in a single run
  • Multi-Mode Minimum Constraint — it defines the minimum timing constraints that must be met across all modes
Correct! MMMC (Multi-Mode Multi-Corner) allows ICC2 to perform timing analysis across all combinations of operating modes (e.g., functional, test) and PVT corners (e.g., setup worst-case, hold best-case) simultaneously. This ensures the design meets timing under all conditions without needing separate runs for each scenario.

3. What is the role of the TLU+ file in ICC2 timing analysis?

  • It defines the clock tree topology and buffer sizes for CTS
  • It lists all the timing exceptions (false paths and multicycle paths) for the design
  • It stores the gate-level netlist in a compact binary format for faster linking
  • It provides RC parasitic models for each metal layer, allowing ICC2 to estimate wire resistance and capacitance during timing analysis before actual routing extraction
Correct! TLU+ (Table Look-Up Plus) files contain pre-characterized RC parasitic models for each metal routing layer, derived from the foundry's process data. ICC2 uses these models to estimate interconnect delay during placement and optimization, before final parasitic extraction (SPEF) is available after routing.

4. What is the difference between a setup corner and a hold corner in MMMC?

  • Setup corners use slow process libraries while hold corners use fast process libraries — they are always opposite PVT conditions
  • Setup and hold corners are identical — the distinction is only in the SDC constraints applied to each
  • A setup corner uses slow/worst-case PVT conditions to find the longest paths that may violate maximum timing. A hold corner uses fast/best-case PVT conditions to find the shortest paths that may violate minimum timing
  • Setup corners apply only to flip-flop data pins; hold corners apply only to clock pins
Correct! Setup analysis checks that data arrives before the clock edge — worst-case slow PVT makes paths longer, so slow corners stress setup. Hold analysis checks that data does not change too soon after the clock edge — best-case fast PVT makes paths shorter, so fast corners stress hold. Both must be analyzed simultaneously in MMMC to ensure the design is robust across all operating conditions.
